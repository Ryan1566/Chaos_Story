# 玩法输入重定向与验收

> 状态：已实现
> Owner：程序
> 最后更新：2026-10-23
> 关联：Story/05_程序/08_EnterScene正式玩法入口迁移.md

按用户本轮指令，将正式玩法从直接读取设备按键改为读取InputManager克隆的同一份InputActionAsset，使设置面板中的重绑定、应用、放弃、恢复默认真正作用于角色。移动、攻击、跳跃保留现有动作与绑定ID；扎营、局内菜单补动作及绑定行。键鼠/手柄都走动作表；固定备用空格仍保留，方向键不再绕过配置提供隐式移动。

输入接口统一处理普通面板、GM、重绑定期间的屏蔽以及界面切换帧；角色清理积存的水平输入/跳跃请求。鼠标点击HUD不同时触发攻击。菜单/扎营快捷入口独立于玩家倒地状态；局内菜单可以进入设置，设置返回后仍保持暂停。旧版Escape/W测试事件继续保留兼容。

本轮不调整战斗数值、掉落、装备或事件规则。仅槽3用于玩法测试；设置文件与字体缓存也在测试后恢复。

## 实现与操作

| 动作 | 默认键鼠 | 默认手柄 | 行为 |
| --- | --- | --- | --- |
| Move | A/D；鼠标两段默认空 | 左摇杆水平轴 | 统一读取动作轴；重绑后不保留原型脚本的隐式方向键兜底 |
| Attack | J / 鼠标左键 | 西侧面键 | 点按一次；鼠标长按设置可按现有0.35秒冷却连发 |
| Jump | K；固定备用空格 | 南侧面键 | 仍按原落地条件跳跃，不改力度 |
| Camp | C；鼠标格默认空 | 北侧面键 | 打开现有扎营界面 |
| Menu | Esc；鼠标格默认空 | Start | 打开/关闭局内菜单，或关闭当前扎营覆盖；设置等普通面板不会被此快捷键跳过 |

设置→按键→更改按键绑定中，键鼠共6行（左右移动、攻击、跳跃、扎营、菜单），手柄5行；两套都沿用原有重绑、清空、重置、应用、放弃流程。菜单增加“设置/按键绑定”入口。键鼠与手柄绑定同时有效，设备页签只决定编辑与显示的方案。

固定空格属于`KeyboardFixed`，不会被其他动作的交互式重绑定采走；绑定页增加提示。采集期间Esc仍按原规则清空当前格，不触发局内菜单。之前空着的格子若被改成已有控制，冲突的另一格也参与互换（原来是空路径时，对方变为未绑定），避免一个按键无提示地触发多个动作。

本轮仅接入原型已具备的移动/近战/跳跃和菜单、扎营快捷操作；没有新增瞄准系统，因此鼠标反转、灵敏度仍没有瞄准消费者。

## 文件与分层

- `GameBase/InputManager/InputManager.Gameplay.cs`：集中提供`ReadMove`、`WasGameplayPressed`、`WasNavigationPressed`、鼠标长按读取、按owner独立维护的屏蔽集合、界面切换帧与按住攻击松键闸门。原`InputManager.cs`改为partial，重绑定继续作用于同一运行时克隆件，原有API保留。
- `PlayerLocomotion/PlayerAttack`：删除硬编码设备轮询；移动与跳跃仍走原物理逻辑，攻击沿用原伤害/命中盒/冷却。角色禁用、UI屏蔽时清理水平输入、跳跃请求与调试输入；鼠标移步、攻击、菜单均过滤指针下的UI射线。
- `UIManager`：Push/Pop、隐藏/恢复局外Canvas后同步自己的输入屏蔽；GM用独立owner注册/释放，关闭GM不会解除下面仍打开的菜单屏蔽。
- `GameplayShortcutDriver`：随局内Ticker创建、随出征清理；独立于角色组件，因此暂停和观战时仍可操作菜单。保留原型TestScene的动作表懒初始化路径，没有额外读取另一份InputActionAsset。
- `RunMenuPresenter/RunMenuPanel`：增加设置入口，设置覆盖期间由既有`RunMenuModel`继续持有暂停状态。
- `Resources/Input/ChaosInputActions.inputactions`：保留原Move/Attack/Jump及已有绑定ID，追加Camp/Menu；修正原可选鼠标移动复合组、鼠标跳跃格子的组名/空路径，使既有界面格子可实际编辑。
- `SettingIds/KeybindBindingsPage/SettingPanel.prefab`：补四个快捷操作行（键鼠2、手柄2），保留原有结构与样式。新标签使用现有本地化回退方式。

设置中的采集仍先写克隆动作表以展示Pending；UI此时屏蔽玩法。应用后保存并继续使用同一覆盖，放弃则恢复Applied。运行时改键没有写入源`.inputactions`文件，已通过前后SHA256核验。

## 运行验收

证据在`Assets/QA/InputRedirect/`。`flow.txt`共140条PASS日志（含重复验证）；不是140个互相独立的测试用例。输入由临时Keyboard/Mouse/Gamepad设备的Input System状态事件注入，跨真实Update/FixedUpdate测量；UI操作使用EventSystem射线校验后发pointer down/up/click，不能冒充人工键鼠或实体手柄测试。

| 项目 | 实测 |
| --- | --- |
| 默认操作 | D实际位移约1.383494；J和鼠标左键各使训练靶50→40；K起跳；C扎营；Esc开关菜单/关闭扎营 |
| 正式UI改键 | 右移D→L，攻击J→I，跳跃K→U，扎营C→V，菜单Esc→Tab；应用落盘并返回暂停菜单；新Tab关闭后恢复游戏 |
| 新旧键 | 旧D/J/K/C/Esc分别不再移动、攻击、跳跃、扎营或打开菜单；L/I/U/V/Tab实际生效；空格仍能跳跃 |
| 默认手柄 | 左摇杆移动、西侧面键攻击、南侧面键跳跃、北侧面键扎营、Start开关覆盖 |
| 手柄重绑 | 移动改右摇杆、攻击改右肩、跳跃改左肩、扎营改方向键上、菜单改右摇杆按下；旧控制失效、新控制实际生效；两套快捷键行可见 |
| 鼠标格 | 攻击改右键后左键不出招、右键造成伤害；右移鼠标格绑中键后实际移动；移到HUD上不再驱动角色 |
| 点按/长按 | 点按模式按住0.9秒只使靶50→40；长按模式同样时间使靶50→20，沿用原冷却 |
| 应用/放弃 | Pending改I→O后放弃恢复I；Esc清空后放弃恢复；离开采集页程序性取消不改原键；改键期间所有玩法读值屏蔽 |

| 固定备用键 | 尝试把攻击绑空格时继续等待；改按B可正常完成；之后固定空格仍能实际起跳 |
