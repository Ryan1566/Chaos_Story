> **历史入口说明（2026-10-25）**：以下保留08阶段实现及原验收，不再代表当前读档/结算落点。当前开始→存档→LoadingScene→MainScene实体村庄；世界地图为M动作辅助子界面，近地块E打开原建造管理，结算回村庄。当前实现和恢复证据见`Story/05_程序/12_MainScene实体村庄实现与验收.md`。本文“一级农田直接收取”旧证据不支持当前免费重复领取；实际Working周期生产与待收获规则以`Story/02_系统策划/24_实体村庄与工作生产.md`为准。

按当时用户指令，以 EnterScene 为正式开发入口。主菜单→存档→局外地图→管理/派遣→LoadingScene→WorldScene→结算/撤离→EnterScene，由正式界面驱动。TestScene 保留作隔离测试，GM 保留快速配置与故障注入，不承担基本玩法的唯一入口。

本轮补齐局外门客、库存、村庄、家族树、市场、时代进度、保存、设置入口；局内提供可点击的行囊/菜单、扎营、撤离及返回战斗。管理面板返回局外，局内子面板返回局内菜单，关闭菜单恢复战斗。返回主菜单先确认并保存，保存失败不退出当前会话。

不扩展输入重绑定、战斗数值、装备效果、掉落/带出规则、重复事件规则。沿用现有服务及 MVP 分层。计时仅为现有建造/伤病 Tick 接入正常运行时驱动，按完整秒推进，GM 仍可快进；不改变产出规则。

验收仅使用槽3并恢复原档，槽1不参与写入。以下为2026-10-22～23的实际运行证据。

## 正式入口与实现

| 位置 | 入口与行为 |
| --- | --- |
| EnterScene主菜单 | 开始游戏→三档存档界面→建档/读档后替换根面板为局外地图 |
| 局外地图 | 门客、库存、村庄、家族树、市场、时代进度、保存进度、设置，共8个管理入口；另有派遣出征、返回主菜单 |
| 村庄 | 建造/取消/升级与收取；一级建筑同时提供升级与收取，不必通过GM调用原有收取服务 |
| 派遣 | 正式编队按钮→LoadingScene→WorldScene，保留原读条及地图准备链路 |
| 局内右上角 | 行囊/菜单→查看本局库存、扎营、继续战斗、撤离；撤离有二次确认，提示放弃本次行囊 |
| 扎营 | 从行囊菜单进入，关闭回到原菜单；继续战斗恢复时间、角色输入和HUD |
| 通关/失败 | 沿用现有结算面板和保存事务；返回EnterScene后自动检查剧情事件 |
| 返回主菜单 | 确认→保存→清会话→主菜单；保存失败保留当前会话与确认框并显示原因，可原地重试 |
| GM测试环境 | 补齐当前会话4名门客、四类资源各至少500；保留建造/伤病快进与旧调试工具，不自动派遣；GM配置同样遵循当前会话保存规则 |

沿用MVP：`WorldMapPresenter/Model`承接管理导航、保存和退出；新增`RunMenuPresenter/RunMenuModel/RunMenuPanel`，Model持有跨扎营覆盖的暂停状态，View只负责控件和渲染。`GameplayUi`复用导航控件；`PanelType.RunMenuPanel`追加在末尾，保留旧枚举数值，`Resources/UIPanels/RunMenuPanel.prefab`已生成。

`UIManager.PopPanel`在下面仍是局内覆盖面板时返回该面板，最后一个局内覆盖关闭才隐藏局外画布。队伍/深度HUD在行囊期间隐藏，恢复战斗后重新显示。原地图层级节点保留；时期预览按钮从正式流程隐藏，GM入口保留。地图信息条避开左上GM按钮。

Entry在框架初始化后挂一份`MetaRuntimeDriver`。仅存在真实存档会话时，累积完整秒再调用原有建造/重伤Tick，避免uint剩余秒数直接接收每帧小数导致计时偏差；可见的村庄/门客Presenter订阅变化后刷新。当前会话变更每30秒尝试保存，应用暂停/退出时补保存；局外手动保存、退出前保存继续可用。此驱动没有实现离线产出，也没有变更现有收取规则。
