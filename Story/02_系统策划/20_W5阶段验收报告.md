## 1. 本阶段验收结论

**结论：通过（可试玩），附带 6 条折扣项、4 条未验证项、3 条遗留。**

## 2. 可验收能力清单（全部有实测证据）

### 2.1 M4 剧情事件

| 能力 | 关键证据 |
| --- | --- |
| 3 种触发条件 | `TriggerType` 1/2/3 分别对应 `runs` / `maxClearedDepth` / `familyTreeNodes`；三种各自实测可触发 |
| 一次性事件 | `runs=1` 时弹《第一次出征》→ 选「收下这份礼」→ **物资 0→50** → 再检查**不再弹**（已写入 `firedEvents`） |
| 可重复事件 | `Repeatable=true` 不写 `firedEvents`；每次回局外最多弹一轮 |
| 排队顺序 | 造 5 个同时满足 → 按 **`Priority` 降序、`Index` 升序**依次弹；单次上限 5；关闭后提示「还有 N 个事件」 |
| 奖励 4 通道 | 给资源（实测物资 +50）、给物品、给门客、加信心；**买入式失败不回滚其它奖励**（物品格位满只提示该项） |
| 真实链路 | **`Depart` → 撤离 → 回局外自动弹事件**（不需要点 GM） |
| 面板 | `EventPanel`：居中、纯中文、标题/正文/选项按钮/关闭；`PanelType.EventPanel` |

### 2.2 M14 地形与阵营

| 能力 | 关键证据 |
| --- | --- |
| 地形差异（表驱动） | `MapBiome` 加 **3 列**（`EnemyHpMul`/`EnemyDmgMul`/`DropGroupBase`），无需新表 |
| 实测三场景数值 | **场景 1 地表 HP 30** → **场景 2 地下 HP 36** → **场景 3 地面建筑 HP 45 / 接触伤害 6 / 掉落组 2** |
| 场景顺序 | 实际 `{Surface, Underground, Building}`（**已被 W5.3 订正进 `17_地形与阵营.md`**；难度非单调递增） |
| 阵营来源 | `Era → 阵营` 映射（秦军 / 楚军 / 汉军）；进场 Toast「地形：地表建筑 · 阵营：汉军」**3 秒**淡出 |
| `FactionMul` | **全 1.00**，仅作标签（避免与 `BaseDifficulty` 双重放大） |
| 不做项核对 | 敌人**数量**不随地形变（`EnemiesPerRoom=2`），3 个场景敌人数量一致 |
| 代码 | `RunTerrainToast.cs`（进场提示）；倍率在敌人生成时覆盖 `EnemyPlaceholder.maxHp/contactDamage` |

### 2.3 M5 市场

| 能力 | 关键证据 |
| --- | --- |
| 价格列 | `Item` 加 `BuyPrice`/`SellPrice`（`uint`），`ItemConfig.cs` 已含两字段（实测） |
| 买 | **500 → 490**（`BuyPrice=10` 的药品）；库存 +1 |
| 卖 | **+5**（`SellPrice=5`）；库存 -1 |
| **买失败退钱** | 格位满时购买失败 → **钱财 500 → 500（未扣）**，提示「格位已满」 |
| 价格约定 | **9/9 行满足 `SellPrice == floor(BuyPrice × 0.5)`**（10/5、8/4、30/15、20/10、10/5、10/5、8/4、30/15、20/10） |
| 只认钱财 | 货币只有 `resMoney`；材料/图纸/物资不参与定价 |
| 面板 | `MarketPanel`：名称/买价/卖价/持有数 + 顶部钱财；按钮灰显给原因（钱财不足 / 格位满 / 叠加满 / 无货） |
| 范围核对 | **无**限购 / 刷新 / 时代调价 / 运送护送 / 批量买卖 |

## 3. M6 局外战斗：**决定不做**（选 B，并入局内）

### 3.1 5 条理由

| # | 理由 |
| --- | --- |
| R1 | **宿主玩法不存在**：M6 定义是"护送"，而 M5 本轮只做兑换，**没有运送/护送** |
| R2 | **会变成第二套战斗规则**：局内已有 `PlayerHealth`/`AllyController`/`EnemyPlaceholder`/门客 HP/扎营补员，再做纯 AI 结算 = 两套数值体感，违背「同一套角色逻辑」 |
| R3 | **验证不了真实体验**：模拟战只能验公式，验不了路线/失败率 |
| R4 | **优先级 2/2 且第二阶段**，W5 已有 M4/M14/M5 |
| R5 | **承接路径已通**：局外冲突 = 「派遣 → 就地进局内战斗」（W2/W3 已验收） |

### 3.2 5 条"证明没做"的验收

| # | 验收项 | 结果 |
| --- | --- | --- |
| A1 | `Scripts/` 无 `MetaBattle*` / `OffRunBattle*` / `SimulatedBattle*` 等新增战斗类 | ✅ 无 |
| A2 | `PanelType` 无 `MetaBattlePanel` 之类；GM 无「局外战斗」版块；`Resources/UIPanels/` 无相关 prefab | ✅ 无 |
| A3 | 推迟结论 R1~R5 已留档（`19_局外战斗.md`）并被索引登记 | ✅ 有 |
| A4 | 派遣链路无回归：派遣 → 出发 → 局内能打 → 撤离 | ✅ 通过 |
| A5 | M5 不受牵连：`MarketPanel` 无任何运送/护送/战斗入口 | ✅ 通过 |
