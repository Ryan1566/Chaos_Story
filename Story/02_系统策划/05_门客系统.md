## 1. 系统概述

| 项目 | 内容 |
| --- | --- |
| 系统名 | 门客（Retainer）：局外培养对象 + 局内可派遣单位 |
| 所属模块 | 概念案 §6 **M2 家族 / 门客培养（亲信）** ＋ **M11 重伤与出战资格** |
| 优先级 | MVP（计划的 W1a） |
| 一句话说明 | 门客是一张**表驱动的角色模板实例**：从 `Retainer` 表按权重招募，持有品质/四项属性/信心/重伤状态；**局外只做管理，局内才战斗**；重伤与低信心会**阻止出战** |
| 上游依赖 | 存档（`SavePayload.retainers`）、`Retainer` 表（W1a 新建）、`Effect` 表（属性/信心加成）、GM 面板 |
| 下游影响 | 派遣编队（W2 只允许"可出战"门客）、局内战斗（W3 用门客属性）、家族树（W1b 提升门客属性/信心上限）、剧情事件（U5 条件） |
| 本系统涉及的配置表 | **`Retainer`（门客表）**；间接读 `Effect`（属性加成，通过家族树/道具） |

### 1.1 设计目标

| # | 目标 | 如何验证 |
| --- | --- | --- |
| G1 | **一眼看出谁能出战** | 门客列表每行都有状态标签：`可用` / `重伤 剩余Ns` / `信心不足`；**不需要点进详情**（概念案 §9 要求状态警示一眼可见） |
| G2 | **重伤不是死亡** | 不存在"死亡"状态；重伤只有**倒计时**，时间到自动恢复为可用 |
| G3 | **数据可存读** | 关 Play 再进（或重读档）后，门客列表、信心、重伤剩余秒数**完全一致** |
| G4 | **表驱动** | 改 `Retainer` 表（属性/初始信心/招募权重）→ 重跑导出 → 新招募的门客表现随之变化，**代码 0 改动** |
| G5 | **不依赖战斗** | 原型期**不接战斗**也能验收：重伤由 GM 手动置、信心由 GM 加减 |

### 1.2 明确不做的（Non-goals）

| # | 不做的事 | 原因 |
| --- | --- | --- |
| N1 | **异形角色（兽形/机械）** | 概念案硬约束：**只做人形态，所有角色走同一套角色逻辑**（数值差异靠表，不靠代码分支） |
| N2 | 死亡机制 | 概念案：**角色没有死亡机制**，只有重伤 |
| N3 | 门客升级/成长曲线 | W1a 只做"模板实例 + 状态"；成长放 W1b（家族树）之后 |
| N4 | 招募界面/抽卡动画 | 原型期招募 = **GM 发放**（按 `RecruitWeight` 随机）或直接给固定 ID |
| N5 | 派遣界面 | W2；本系统只提供"可出战判定"给 W2 用 |
| N6 | 离线计时 | U2：原型期只算运行中时间（见 §5.3） |

### 2.1 门客 vs 族人（术语边界 · 用户 2026-10-18 裁决）

> ⚠️ **这两个词不是同义词，不能混用。**

| 术语 | 英文 | 是什么 | 能做什么 | 本轮状态 |
| --- | --- | --- | --- | --- |
| **门客** | `Retainer` | **可被选中派遣进入局内战斗的角色**（**本文的对象**） | 出战、重伤 / 信心、属性成长、被派遣进局 | **W1a 已落地 / W2 接入派遣** |
| **族人** | `Clansman` | **不参战的 NPC** | **村庄建造用工**、参与**局外事件** | **本轮不实现**（只定名分与边界） |

- 凡涉及「建造用工」「局外事件 NPC」时**必须写「族人（`Clansman`）」**，不要写成门客。
- 表文件中文名同步改为 `Retainer_门客表.xlsx`（由**程序**改名，策划不动 Excel）。
- 概念案 §11 已按本次裁决**拆成两条并定稿**（原「亲信 / 族人 → `Retainer` / `Clansman`（待定稿）」）。

## 3. 规则详述

| # | 规则 | 触发条件 | 结果 | 例外 |
| --- | --- | --- | --- | --- |
| R1 | **招募**：从 `Retainer` 表按 `RecruitWeight` 加权随机一个模板 → 生成实例 | GM 点「给 1 个随机门客」 | 新增一个实例（`id` 自增、`protoId` = 模板 Index、`quality` = 模板品质、`hp` = 模板 Hp、`confidence` = 模板初始信心、`wounded=false`） | `RecruitWeight = 0` 的模板**不参与**随机 |
| R2 | **可出战判定** | 任何需要"能否出战"的地方（列表标签 / 派遣校验） | `可出战 = (!wounded) && (confidence >= 30)` | 重伤**优先**显示（同时不满足时标签显示重伤） |
| R3 | **重伤产生** | **原型期**：GM 点「打伤选中门客」 | `wounded = true`；`woundedRemainSeconds = 模板/常量时长`（见 §4 F2） | W3 之后才由战斗/事件产生；**本系统不绑战斗** |
| R4 | **重伤恢复** | `woundedRemainSeconds` 递减到 `0` | 自动 `wounded = false`、`woundedRemainSeconds = 0`；**信心不变** | 无 |
| R5 | **信心下降** | GM 点「信心 -40」（原型期）／将来的事件 | `confidence = clamp(confidence - 40, 0, 100)` | 信心**不会**因重伤自动下降（W1a 分开处理） |
| R6 | **信心恢复** | GM 点「信心 +40」／事件／家族树（W1b） | `confidence = clamp(confidence + 40, 0, 100)` | 无 |
| R7 | **属性读取** | 需要展示或给战斗用时 | `最终属性 = 模板属性 + Σ(Effect 加成)`（按 `08_Effect_` 的叠加规则，增量相加） | 信心上限也可被 `Effect` 提升（`EffectType=4`，`Target=5`） |
| R8 | **门客数量不占格位** | — | 门客数量**不受"格位 8"限制**（格位只管**物品种类**，见 `06_资源与库存.md`） | 无 |
| R9 | **状态标签优先级** | 列表渲染时 | 重伤 > 信心不足 > 可用（一次只显示一个主标签，避免歧义） | 无 |

### 3.1 规则之间的优先级

> 同时命中多条时：**可出战判定（R2）> 重伤时长（R4）> 信心变化（R5/R6）**。
> 即：先由 R4 结束重伤，再判 R2；信心变化**不会**打断重伤倒计时（W1a 保持两套独立状态）。

### 3.2 「可出战」判定（**口径原文，程序按此实现**）

```
可出战 = (!wounded) && (confidence >= ConfidenceThreshold)
ConfidenceThreshold = 30   // 常量；待确认（§12 Q1）
```

- **重伤未愈**：无论信心多少，**都不可出战**。
- **信心不足**（`< 30`）：即使没重伤，**也不可出战**。
- **只做判定，不做拦截提示的文案强约束**：文案由 UI 用 `LocalizedText` 取（§8）。

### 3.6 局内生命：HP / 受伤 / 倒地 / 补员（**W3.3**）

> 完整规则见 **`Story/02_系统策划/15_门客生命与阵亡.md`**；本节只列与局外规则衔接的要点。

| # | 要点 | 说明 |
| --- | --- | --- |
| K1 | **局内 HP 上限 = `Retainer.Hp`** | 直接用表中已有字段（**表结构不改**）；属性类 `Effect`（`EffectType=4 / Target=1`）可加成 |
| K2 | **局内 HP 是纯运行时值、不落盘** | 撤离 / 通关 / 失败结算后**回满**；`RetainerSave.hp` 本波仍不写（保留给将来跨局带伤） |
| K3 | **HP 归零 = 倒地（不是死亡）** | 不可操作 / 不可被攻击 / 不跟随；本局内不能自行起身 |
| K4 | **倒地 → 回局外记为重伤** | 结算时对倒地者调 `RetainerService.Wound(id, 30)` → `wounded=true` + **30s** 倒计时（沿用本文 §3 的重伤规则，Q1 缺省阈值不变） |
| K5 | **扎营「补充减员」= 半血复活** | 倒地门客回到 `ceil(MaxHp × 50%)` 并可继续参战；需家族树节点 `303`；每局 1 次、消耗药品 ×2 |
| K6 | **失败判定改为「全队倒下」** | `受控角色倒下 且 全部门客倒地` → 本局失败；**门客全倒但玩家还活着不算失败**（口径见 `12_结算与进度.md` §3.4） |
| K7 | **不要再把"门客全倒"当失败** | 旧实现（受控角色归零即失败）在 W3.3 改造后不再符合口径 |

## 4. 数值与公式

| # | 数值 / 公式 | 含义 | 来源 | 取值范围 |
| --- | --- | --- | --- | --- |
| F1 | `Hp/Attack/Defense/Speed` | 门客四项基础属性 | **`Retainer` 表**（模板） | 整数 ≥1（`Hp` ≥ 1；其余 ≥ 0） |
| F2 | `WoundedSeconds` | 重伤持续秒数 | **常量**（原型期）：**30 秒**（便于 GM 演示）；将来按表或难度 | 1~600 |
| F3 | `Confidence` | 信心 | 初始来自模板 `InitialConfidence`；运行时增减 | `0~100`（clamp） |
| F4 | `ConfidenceThreshold` | 可出战信心阈值 | **常量 30** | `0~100` |
| F5 | `可出战` | 派生（不落盘） | R2 | `true/false` |

### 4.1 取整与边界

| 项目 | 规定 |
| --- | --- |
| 属性类型 | **全部整数**（`Hp`/`Attack`/`Defense`/`Speed` 用 `uint`），**不用 `float`**（概念案 §7：人形态统一逻辑、属性整数） |
| 信心 | 整数 `0~100`；**每次变化后 clamp**，不存超界值 |
| 重伤剩余秒数 | **整数秒**；显示向下取整（`25.7s` 显示 `25s`） |
| 时间口径 | **仅运行中计时**（U2）：用 `Time.unscaledDeltaTime` 累减；**暂停（`timeScale=0`）也要继续**（用 unscaled，避免 `BasePanel.PauseTime` 卡住倒计时） |

### 4.2 数值调优入口

| 想调什么 | 改哪个 | 是否需重新导出 | 是否需重启 |
| --- | --- | --- | --- |
| 门客基础属性 / 初始信心 / 招募权重 | `Retainer` 表（`Excel/Chaos_excel/Retainer_门客表.xlsx`） | **是**（跑 `ExcelTool/ExportExcelConfigs`） | 重进 Play 即可 |
| 可出战信心阈值 | **常量**（`ConfidenceThreshold`） | 否 | 是（待确认是否移入表，§12 Q1） |
| 重伤时长 | **常量**（`WoundedSeconds`） | 否 | 是（将来按表） |

## 5. 状态与流程

### 5.1 门客实例状态机

| 状态 | 进入条件 | 允许的动作 | 退出条件 | 去向 |
| --- | --- | --- | --- | --- |
| **可用** | `!wounded && confidence>=30` | 可被派遣（W2） | 重伤（R3）／信心跌破阈值（R5） | 重伤 / 信心不足 |
| **重伤** | `wounded=true` | 只能查看（不可派遣） | `woundedRemainSeconds` 归 0（R4） | 可用（若信心够）／信心不足 |
| **信心不足** | `!wounded && confidence<30` | 只能查看 | 信心恢复到 ≥30（R6） | 可用 |

### 5.2 招募流程（原型期）

```
GM → 系统 → 门客 → 「给 1 个随机门客」
  → 按 RecruitWeight 加权随机一个 Retainer 模板
  → 生成实例：id 自增；protoId=模板 Index；quality=Quality；
     hp=模板 Hp；confidence=模板 InitialConfidence；wounded=false
  → 门客列表出现新行（状态标签「可用」）
  → 立即写存档（或标记 dirty，由存档服务统一落盘）
```

### 5.3 计时口径（**U2 裁决 + 未来切换点**）

| # | 口径 |
| --- | --- |
| T1 | **原型期只算"运行中时间"**：`woundedRemainSeconds` 每帧按 `Time.unscaledDeltaTime` 递减；**关闭游戏期间不走**（离线回来仍是离开时的剩余秒数） |
| T2 | **落盘字段用"剩余秒数"**：`RetainerSave.woundedRemainSeconds`（`uint`）。⚠️ 现有 `RetainerSave.woundedUntilUtcTicks`（`long`，UTC ticks 语义）**本阶段保留但恒为 0、不读取**（见 §6.2） |
| T3 | **将来切换真实时间**（W4 前）：把"读剩余秒数"改成"读 `woundedUntilUtcTicks` 与当前 UTC 比较"，**只改这一处读写**；`woundedUntilUtcTicks` 的语义**不需要变**（仍是"到期时刻"），因此**不需要 `version+1`** |
| T4 | 暂停菜单（`timeScale=0`）期间：重伤倒计时**继续走**（用 unscaled），理由：这是"时间在流逝"的叙事，且避免玩家用暂停规避 |

### 5.4 时序（与存档服务）

| 顺序 | 发起方 | 接收方 | 消息 / 调用 | 备注 |
| --- | --- | --- | --- | --- |
| 1 | GM / 招募 | 门客服务 | `Recruit(protoId or weight)` | 生成实例 |
| 2 | 门客服务 | `SavePayload.retainers` | 追加 `RetainerSave` | **只加字段/加元素**，零迁移 |
| 3 | 门客服务 | 存档服务 | 标记 dirty / `Save(slot, payload)` | 存档写入由存档服务统一负责 |
| 4 | 每帧 | 门客服务 | `Tick(unscaledDeltaTime)` | 递减重伤秒数 |
| 5 | 门客服务 | 门客面板 | 刷新列表与标签 | 事件或每帧轮询由程序定 |

## 6. 数据结构

### 6.1 运行时结构（不落盘）

| 字段 | 类型 | 含义 | 需要存档？ |
| --- | --- | --- | --- |
| `RuntimeId` | `uint` | 实例唯一 ID（与存档 `id` 同源） | 是（落 `id`） |
| `ProtoId` | `uint` | `Retainer.Index` 模板外键 | 是（**新增字段**） |
| `Confidence` | `int` | 当前信心 | 是 |
| `WoundedRemainSeconds` | `uint` | 重伤剩余秒数 | 是（**新增字段**） |
| `IsWounded` | `bool` | 是否重伤（派生：`Remain>0`） | 是（落 `wounded`） |

### 6.2 存档映射（**与现有 `RetainerSave` 逐字段对齐**）

> 现有结构（`Scripts/Runtime/GameBase/SaveManager/SaveSlotData.cs`，实测）：
> `RetainerSave { uint id; uint quality; int hp; int confidence; bool wounded; long woundedUntilUtcTicks; }`

| `RetainerSave` 字段 | 现有含义（代码注释） | 本系统怎么用（**明确**） |
| --- | --- | --- |
| `id` | 未注释 | **复用**：实例唯一 ID（`1` 起自增） |
| `quality` | 未注释 | **复用**：实例品质 `1~5`；初始 = 模板 `Quality`（保留将来"提升品质"的可能） |
| `hp` | 未注释 | **复用**：**当前生命值**；局外不战斗 → 等于模板 `Hp`（满血）。W3 战斗后可能低于上限 |
| `confidence` | 未注释 | **复用**：当前信心 `0~100` |
| `wounded` | 未注释 | **复用**：是否重伤 |
| `woundedUntilUtcTicks` | "重伤到期时刻，UTC ticks；0 = 未重伤" | ⚠️ **语义保留、本阶段不使用**：原型期恒填 `0`、不读取（因为 U2 只算运行中时间）。W4 切真实时间时**直接启用**，语义不变 |
| **`protoId`**（**需新增**） | — | `uint`，`Retainer.Index` 外键（模板来源） |
| **`woundedRemainSeconds`**（**需新增**） | — | `uint`，重伤剩余秒数（原型期真正读写的字段） |

> **零迁移说明**：`protoId` / `woundedRemainSeconds` 是**新增 public 字段**，老存档读进来取默认值（`0`），不报错、不需要迁移代码（`SaveSlotData.cs` 顶部注释已写明该机制）。
> ⚠️ **不要改 `woundedUntilUtcTicks` 的语义**（改成"剩余秒数"就属于不兼容变更，要 `version+1` 并写迁移分支）。

### 6.3 表数据 → 实例的字段来源

| 实例字段 | 来源 |
| --- | --- |

### 6.4 供其他系统读取的字段（**U5：事件触发条件**）

| 条件 | 字段 | 所在 | 谁读 |
| --- | --- | --- | --- |

## 9. 边界与异常

| # | 场景 | 期望行为 |
| --- | --- | --- |
| E1 | 门客列表为空 | 面板显示空态（占位文案），**不报错** |
| E2 | `Retainer` 表为空 / 全部 `Enable=false` | 招募失败 → 提示"无可用模板"并记 warning；**不崩溃** |
| E3 | 存档里的 `protoId` 在表中不存在（表被改/删） | 该门客**保留在列表**但显示"未知模板"占位（属性取存档 `hp`/`quality`），记 warning；**不得删数据** |
| E4 | 信心被减到 0 或加到 >100 | clamp 到 `0~100` |
| E5 | 重伤秒数被减到 <0 | 归 0 并结束重伤（R4） |
| E6 | 同一帧多次置伤 | 只生效一次（重复置伤只重置倒计时） |
| E7 | 老存档（无 `protoId`/`woundedRemainSeconds`） | 正常读取；`protoId=0` 走 E3 的占位分支；`woundedRemainSeconds=0` 视为未重伤 |
| E8 | 暂停菜单中 | 重伤倒计时**继续走**（§5.3 T4） |
