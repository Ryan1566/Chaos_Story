## 1. 系统概述

| 项目 | 内容 |
| --- | --- |
| 系统名 | 村庄建设 / 经营（Village Building） |
| 所属模块 | 概念案 §6 **M1 村庄建设 / 经营** |
| 优先级 | MVP（计划的 W1b） |
| 一句话说明 | 局外村庄有若干个**建筑**；每个建筑有**等级**，建造/升级要**耗时**与**消耗资源**，建成后**按周期产出资源**（需玩家点收取）；一次只能造 1 个 |
| 上游依赖 | 资源与库存（`06_资源与库存.md`，消耗/产出）、`Building` 表（W1b 新建）、`Effect`（建造时长/收获产量加成）、存档 `SavePayload.buildings` |
| 下游影响 | 家族树（W1b，产业板块降低建造时长/提升产量）、市场（W5，卖资源）、派遣（W2 传送阵台） |
| 本系统涉及的配置表 | **`Building`（建筑表，每级一行）**；间接读 `Effect`（类型 6 建造时长 / 类型 7 收获产量） |

### 1.1 设计目标

| # | 目标 | 如何验证 |
| --- | --- | --- |
| G1 | **建造是"等出来"的，不是瞬间完成** | 点「建造」后格子上出现倒计时条，**秒数来自表**（`Building.BuildSeconds`） |
| G2 | **产出靠周期收获** | 建成后按 `HarvestSeconds` 累积，玩家点「收取」→ 资源数字增加；**不点不自动进账** |
| G3 | **一次只造一个** | 队列已占用时，其它建筑的「建造」按钮置灰并提示"正在建造中" |
| G4 | **表驱动** | 改 `Building` 表的时长/产量/消耗 → 重导 → 表现随之变化，代码 0 改动 |
| G5 | **数据可存读** | 建筑等级、是否在建造、剩余时间关 Play 再进完全一致（离线不推进，U2） |
| G6 | **效果可叠加** | 家族树点亮"农田建造 -5 秒"后，农田建造时长**按效果减少**（不低于 1 秒） |

### 1.2 明确不做的（Non-goals）

| # | 不做的事 | 原因 |
| --- | --- | --- |
| N1 | 建筑摆放/自由布局 | MVP 用**固定格子**（按 `Building.Index` 排），不做出网格摆放 |
| N2 | 多建造队列 | 决策：**1 条队列**（§3.3），多队列放后续 |
| N3 | 建筑拆迁/降级 | 不做（避免资源回收漏洞） |
| N4 | 离线收益 | **U2**：离线不走表；收获也不在离线期间累积（§5.5） |
| N5 | 建筑外观分级 | 占位美术；等级只影响数值与图标角标 |

## 2. 术语表

| 术语 | 含义 | 备注 |
| --- | --- | --- |
| 建筑 / `Building` | 村庄里可建造的设施（农田/工坊/集市/书斋） | `Building.Index` = **建筑 ID**（如 2001） |
| 等级 / `Level` | 同一建筑的等级，`1..N`；**每级一行配置** | 本作 MVP 每建筑 2 级 |
| 建造队列 | "正在建造/升级"的唯一槽位 | 只有 1 条 |
| 建造时长 / `BuildSeconds` | 建造/升级所需秒数 | 来自表；可被 `Effect` 类型 6 缩短 |
| 收获周期 / `HarvestSeconds` | 每 N 秒累积一份产出 | 来自表 |
| 待收取 / Pending | 已累积但未点收取的产出 | 需落盘（否则退出就丢） |
| 收取上限 | 待收取最多累积几份 | 建议 8 份（**待确认** Q4） |

## 3. 规则详述

### 3.1 建筑清单（4 个）

| `Index`（建筑 ID） | 建筑 | 产出资源 | 说明 |
| --- | --- | --- | --- |
| `2001` | **农田** | 物资（`resGoods`） | 基础产出；**已有 `Effect` 4 指向它**（建造 -5 秒） |
| `2002` | **工坊** | 材料（`resMaterial`） | 产出材料 |
| `2003` | **集市** | 钱财（`resMoney`） | 产出钱 |
| `2004` | **书斋** | 图纸（`resBlueprint`） | 产出图纸（周期最长） |

> 每个建筑 **2 个等级**（L1 建造 → L2 升级），配置上每级一行，共 **8 行**（见 `12_Building_字段规格.md`）。

### 3.2 规则表

| # | 规则 | 说明 |
| --- | --- | --- |
| R1 | **建造**：未建 → L1 | 消耗 `CostResourceType/CostAmount`；占用队列；`BuildSeconds` 后完成 |
| R2 | **升级**：L(n) → L(n+1) | 同一建筑**必须先建成当前级**；消耗按目标级的行配置 |
| R3 | **等级上限** | 表里该建筑的最大 `Level`；已达上限时按钮显示「已满级」 |
| R4 | **资源不足** | 拒绝建造/升级，提示"资源不足"；**不扣资源** |
| R5 | **队列占用** | 已有建造任务时，其它建筑按钮置灰（提示"正在建造（剩余 Ns）"） |
| R6 | **取消建造** | 可取消，**返还 50% 消耗资源（向下取整）**；取消即释放队列（**待确认** Q2） |
| R7 | **收获累积** | 建成后每 `HarvestSeconds` 累积 `OutputAmount`；**累积到上限即停止**（不产出、不溢出） |
| R8 | **收取** | 玩家点收取 → 待收取全部进资源数字；待收取清零 |
| R9 | **效果影响** | 建造时长 = `max(1, BuildSeconds - Σ(EffectType=6 的 Value))`；收获产量 = `OutputAmount + Σ(EffectType=7 的 Value)` |
| R10 | **建筑数固定** | 4 个建筑格**常驻显示**（未建显示「可建造」），不做"建造新格子" |

### 3.3 建造队列

| # | 规定 |
| --- | --- |
| Q1 | **只有 1 条队列**：同时只能有一个建造/升级任务 |
| Q2 | 队列状态落盘：`buildingId` + `targetLevel` + 剩余秒数 |
| Q3 | 取消只允许"进行中"的任务；已完成任务不可取消（无意义） |

### 3.4 规则优先级

`资源校验（R4）` > `队列校验（R5）` > `等级校验（R3）` > `开始建造（R1/R2）`。

## 4. 数值与公式

| # | 数值 / 公式 | 含义 | 来源 | 范围 |
| --- | --- | --- | --- | --- |
| F1 | `BuildSeconds` | 建造/升级秒数 | `Building` 表 | 1~3600（示例 30~180） |
| F2 | `HarvestSeconds` | 收获周期 | `Building` 表 | 1~3600（示例 30~120） |
| F3 | `OutputAmount` | 每次产出数量 | `Building` 表 | ≥1 |
| F4 | `CostResourceType/CostAmount` | 建造消耗 | `Building` 表 | 类型 1~4；数量 ≥0 |
| F5 | `实际建造时长 = max(1, BuildSeconds - Σ Effect(类型6, Target=建筑ID))` | 效果缩短 | `Effect` 聚合 | ≥1 秒 |
| F6 | `实际每次产出 = OutputAmount + Σ Effect(类型7, Target=建筑ID)` | 效果提升 | `Effect` 聚合 | ≥0 |
| F7 | `取消返还 = floor(CostAmount × 50%)` | 退款 | R6 | ≥0 |

### 4.1 取整与边界

| 项目 | 规定 |
| --- | --- |
| 时间 | 秒（`float` 显示向下取整到整秒：`29.4s → 29s`） |
| 产量/消耗 | 整数（`uint`） |
| 退款 | 向下取整（`floor`），避免"造了又退"套利 |
| 计时 | **仅运行中计时**（U2）：`Time.unscaledDeltaTime`，暂停菜单期间继续走 |

### 4.2 调优入口

| 想调什么 | 改哪里 | 需重新导出 |
| --- | --- | --- |
| 建造时长 / 产量 / 消耗 / 等级 | `Building` 表 | **是** |
| 建造时长减免、产量提升 | `Effect` 表（类型 6/7） | **是** |
| 队列数（1）、退款比例（50%）、收取上限（8） | **常量**（待确认是否移表） | 否 |

## 5. 状态与流程

### 5.1 建筑状态机

| 状态 | 进入条件 | 可做 | 退出 |
| --- | --- | --- | --- |
| **未建** | `level = 0` | 点「建造」（消耗 L1 资源、占队列） | 建造完成后 → 已建 L1 |
| **建造中** | 有队列且目标为本建筑 | 查看倒计时 / 取消 | 完成 → 已建目标级；取消 → 回到原状态 |
| **已建** | `level ≥ 1` 且未在升级 | 收获 / 升级 | 升级 → 建造中 |
| **满级** | `level = 表内最大 Level` | 收获 | — |

### 5.2 建造流程

```
点击「建造/升级」
  ├─ 资源够？ ── 否 → 提示"资源不足"，终止（不扣资源）
  ├─ 队列空闲？ ── 否 → 提示"正在建造（剩余 Ns）"，终止
  ├─ 扣资源（SpendResource）
  ├─ 记录建造任务：buildingId / targetLevel / remainSeconds = 实际建造时长（F5）
  └─ 每帧 Tick：remainSeconds -= unscaledDeltaTime
        └─ ≤0 → 完成：level = targetLevel；queue 清空；写存档
```

### 5.3 收获流程

```
每帧 Tick（已建建筑）：
  accumulate += unscaledDeltaTime
  while accumulate ≥ HarvestSeconds 且 待收取份数 < 上限:
      accumulate -= HarvestSeconds
      待收取份数 += 1
  （到上限后 accumulate 停在上限附近，不再累积）   ← 建议行为，待确认 Q4

点「收取」：
  资源 += 待收取份数 × 实际每次产出（F6）
  待收取 = 0；accumulate = 0；写存档
```

### 5.4 计时口径（**U2 裁决 + 未来切换点**）

| # | 口径 |
| --- | --- |
| T1 | **原型期只算运行中时间**：建造剩余秒数、收获累积都用 `Time.unscaledDeltaTime` 递减；**关闭游戏期间不走** |
| T2 | **落盘存"剩余秒数"**而不是"完成时刻"：`BuildingSave.remainSeconds`（`uint`） |
| T3 | 现有 `BuildingSave.finishUtcTicks`（`long`，UTC ticks 语义）**本阶段保留但不使用**（恒 0）。W4 切真实时间时改成"读 `finishUtcTicks` 与当前 UTC 比较"，**只改这一处读写**，字段语义不变 → **不需要 `version+1`** |
| T4 | 暂停菜单期间**继续走**（unscaled），避免用暂停规避建造时间 |

### 5.5 离线语义（与 U2 一致）

| 场景 | 行为 |
| --- | --- |
| 关游戏 1 小时再开 | 建造**没有推进**（剩余秒数不变）；待收取也**没有增加** |
| 说明 | 这是**原型期的简化**；W4 若改真实时间，需同时定义"离线收益上限"（**待确认** Q5） |

## 6. 数据结构

### 6.1 运行时结构

| 字段 | 类型 | 含义 | 落盘 |
| --- | --- | --- | --- |
| `BuildingId` | `uint` | `Building.Index` | 是 |
| `Level` | `uint` | 当前等级（0=未建） | 是 |
| `IsBuilding` | `bool` | 是否在建造/升级 | 派生（`remainSeconds>0`） |
| `RemainSeconds` | `uint` | 建造剩余秒数 | 是 |
| `PendingCharges` | `uint` | 待收取份数 | 是 |
| `Accumulate` | `float` | 收获累积秒数 | 建议落盘（否则退出丢精度） |

### 6.2 存档映射（**与现有 `BuildingSave` 对齐**）

> 现有结构（`SaveSlotData.cs` 实测）：`BuildingSave { uint id; uint buildingType; uint level; bool completed; long finishUtcTicks; }`

| 字段 | 现有含义 | 本系统怎么用 |
| --- | --- | --- |
| `id` | — | **复用**：建筑实例 ID（MVP 每个建筑 1 个实例，= `BuildingId`） |
| `buildingType` | — | **复用**：建筑类型 = `Building.Index`（与 `id` 同值，保留扩展） |
| `level` | — | **复用**：当前等级（0 = 未建） |
| `completed` | — | **复用**：`level ≥ 1`（派生，冗余存便于快速判断） |
| `finishUtcTicks` | "完工时刻，UTC ticks；0 = 未在建造" | ⚠️ **语义保留、本阶段不使用**（恒 0）；W4 切真实时间时启用 |
| **`remainSeconds`**（需新增） | — | **`uint`**，建造剩余秒数（原型期真正读写） |
| **`pendingCharges`**（需新增） | — | **`uint`**，待收取份数 |
| **`harvestAccum`**（需新增） | — | **`float`**，收获累积秒数（避免退出丢进度） |

> **零迁移**：新增字段老存档读进来取默认 0，不报错、不需要迁移代码。
> ⚠️ **不要改 `finishUtcTicks` 的语义**（改成"剩余秒数"属不兼容变更 → 需 `version+1`）。
