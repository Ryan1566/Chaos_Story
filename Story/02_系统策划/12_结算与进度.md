## 3. 规则详述

### 3.1 触发条件

| # | 事件 | 结算类型 | 触发点 |
| --- | --- | --- | --- |
| R1 | 第 3 场景清空（boss 占位被清） | **通关结算** | `RunEncounter.RunCleared == true` |
| R2 | 全队倒下 | **失败结算** | 见 §3.4（当前需程序提供失败信号） |
| R3 | 主动撤离（`DispatchService.ReturnToMeta`） | **不结算**（视为放弃） | 撤离按钮 |

> **撤离不算通关、也不算失败**：不 +1 任何进度；局内掉落丢失（见 `10_局内掉落与带出.md`）。

### 3.2 通关结算（**严格按此顺序**）

| 步 | 动作 | 数据变化 | 说明 |
| --- | --- | --- | --- |
| 1 | 标记 boss 已清 | `MarkBossCleared()` | 双门槛之一 |
| 2 | 标记第 3 场景已清 | `MarkSceneCleared(3)` | `scenesCleared` 增加 |
| 3 | **带出流程** | 见 `10_局内掉落与带出.md` | 先让玩家选，再写局外库存 |
| 4 | 累计通关 +1 | `clears += 1` | 里程碑统计量 |
| 5 | **深度 +1** | `TryAdvanceDepth()`（内部按 `DepthCap` 截断） | 到顶则不变，并提示「深度已到当前时代上限」 |
| 6 | 更新历史最大深度 | `maxClearedDepth = max(maxClearedDepth, depth)` | **事件条件 U5-②** |
| 7 | **尝试时代推进** | `TryAdvanceEra()`（双门槛） | 成功 → `era += 1`（且**只 +1**） |
| 8 | 展示结算面板 | — | 显示本次变化（§3.3） |
| 9 | 落盘 | 存档服务统一保存 | 零迁移字段 |

### 3.3 结算面板要显示什么

| 项 | 内容 | 数据来源 |
| --- | --- | --- |
| 结果 | 「通关」/「失败」 | 结算类型 |
| 带出 | 「带出 N 件」（含列表） | 带出结果 |
| 深度 | 「深度 X → Y」（到顶显示「已满（X/上限）」） | `depth` / `DepthCap` |
| 累计通关 | 「累计通关 N」 | `clears` |
| 时代 | 「时代不变」/「时代 X → X+1」 | `era` |
| 时代未推进的原因 | 「需再通关 N 次」/「需点亮家族树节点」 | `Era.MilestoneType` 与差值 |
| 提示 | 「按确认返回局外」 | — |

### 3.4 失败结算

| # | 规则 |
| --- | --- |
| F1 | **不进入带出流程**（`10_局内掉落与带出.md` §3.5） |
| F2 | **`runs` 不变**（出发时已 +1，失败不减免也不再加） |
| F3 | **`clears` / `depth` / `era` 都不变** |
| F4 | 门客按规则变**重伤**（倒计时，见 `05_门客系统.md`）；**不死亡** |
| F5 | 局内掉落：原型建议**全部丢失**（**与用户原话「失败也能带回部分收获」有偏差 → 待用户拍板**，`10_局内掉落与带出.md` Q3） |
| F6 | 结算面板显示「失败 · 本次未获得任何带回」+ 「门客已重伤（Ns）」 |

### 3.5 时代推进（双门槛，**只 +1**）

```
可推进 ⇔ BossClearedThisRun（本局打过第 3 场景 boss 占位）
        ∧ 局外统计量 ≥ Era[当前时代].MilestoneValue
实现：MetaProgressService.TryAdvanceEra()（内部判两个条件）
  ├─ era >= 5 → 不可推进（「已是最后时代」）
  └─ 成功 → era += 1（**一次只 +1**，不当场连锁推进）
```

- **里程碑类型**（`Era.MilestoneType`）：`1` = 累计通关数 `clears`；`2` = 家族树已点亮节点数 `familyTreeNodes.Count`。
- 未满足时，结算面板要**说清差多少**（例：「需累计通关 3 次（当前 1）」）。

### 3.6 幂等（**防重复结算**）

| # | 规则 |
| --- | --- |
| I1 | 每局只结算一次：结算开始时置 `settled = true`（局内状态，不落盘），后续调用直接返回 |
| I2 | 结算完成即进入"已结束"状态，必须**返回局外**才能再派遣（`DispatchService.ReturnToMeta`） |
| I3 | 若结算中途异常（存档失败），**不得**把 `settled` 置真（允许重试）；`MetaProgressService` 的 +1 必须与存档成功**一致**（见 §9 E3） |

### 3.7 规则优先级

`I1 幂等` > `R1 通关` > `R2 失败` > `R3 撤离`（三者互斥，先判定先赢）。

## 4. 数值与公式

| # | 数值 / 公式 | 说明 | 来源 |
| --- | --- | --- | --- |
| F1 | `clears += 1` | 每次通关 +1 | 本次结算 |
| F2 | `depth = min(depth + 1, DepthCap)` | 到顶不增 | `TryAdvanceDepth` |
| F3 | `maxClearedDepth = max(maxClearedDepth, depth)` | 只增不减 | 本次结算 |
| F4 | `era += 1`（条件成立且 `era < 5`） | 一次 1 级 | `TryAdvanceEra` |
| F5 | `DepthCap = era` | 派生 | `MetaProgressService.DepthCap` |
| F6 | `DeployCap = clamp(1 + ΣEffectType=3, 1, 10)` | 带出上限 | `MetaProgressService.DeployCap` |
| F7 | 难度取值 | `Era.BaseDifficulty + Depth[era,depth].DifficultyDelta` | `07_Era与Depth_字段规格.md` |

### 4.1 取整与边界

| 项目 | 规定 |
| --- | --- |
| `era` | `1~5`，只增不减 |
| `depth` | `1~era`（`era` 提升后**不重置**，上限随之变大） |
| `clears`/`runs` | `uint` 只增 |
| 展示 | 深度显示 `当前/上限`（如 `深度 2/2`） |

## 5. 状态与流程

### 5.1 一局的生命周期（与进度）

| 阶段 | 触发 | 进度变化 |
| --- | --- | --- |
| 出发 | `DispatchService.Depart` | **`runs += 1`**（U5-①） |
| 场景 1/2/3 清空 | `MarkSceneCleared(i)` | `scenesCleared` |
| 通关 | §3.2 | `clears/depth/maxClearedDepth/era` |
| 失败 | §3.4 | 无进度变化 |
| 撤离 | `ReturnToMeta` | 无进度变化 |
| 回局外 | `ReturnToMeta` | `IsInRun=false`，可再次派遣 |

### 5.2 流程图

```
出发（runs+1）
   │
   ├─ 打完 3 场景 → 通关
   │     ① MarkBossCleared ② MarkSceneCleared(3)
   │     ③ 带出勾选（≤ DeployCap）  ④ clears+1
   │     ⑤ depth+1（≤era 截断）  ⑥ maxClearedDepth=max
   │     ⑦ TryAdvanceEra（双门槛）  ⑧ 结算面板  ⑨ 落盘
   │
   ├─ 全队倒下 → 失败
   │     不带出 / 进度不变 / 门客重伤 / 结算面板
   │
   └─ 主动撤离 → 无结算（掉落丢失）
```

### 5.3 时序

| 顺序 | 发起方 | 接收方 | 动作 |
| --- | --- | --- | --- |
| 1 | `RunEncounter` | 结算服务 | `OnRunCleared()` |
| 2 | 结算服务 | `MetaProgressService` | `MarkBossCleared` / `MarkSceneCleared(3)` |
| 3 | 结算服务 | 带出流程 | 勾选 → 写局外库存 |
| 4 | 结算服务 | `MetaProgressService` | `clears+=1` / `TryAdvanceDepth` / `TryAdvanceEra` |
| 5 | 结算面板 | — | 显示结果 |
| 6 | 确认 | 存档服务 + `DispatchService` | 保存 + `ReturnToMeta` |

## 9. 边界与异常

| # | 场景 | 期望行为 |
| --- | --- | --- |
| E1 | 重复触发通关 | 幂等：第二次直接返回（I1），不再 +1 |
| E2 | `era=5` 已满 | 不推进，提示「已是最后时代」 |

| E5 | `Depth` 表缺某组合 | 该深度难度按"最大可用深度"回退 + Warn（`07_` K3） |
| E6 | `Era` 表缺失当前时代行 | 里程碑不可判定 → 不推进 + Error 日志 |
| E7 | 撤离后立即再派遣 | 允许；`runs` 已 +1 不重复加 |

## 12. 验收标准（可测试）

| # | 验收项 | 判定方式 |
| --- | --- | --- |
| A1 | 通关 +1 | `clears` 恰好 +1；`scenesCleared` 增加 |
