## 3. 折扣项（如实）

1. **攻击/跳跃无动画**：`Citizen_001` 只有 3 个动画，攻击只用"前移 + 掉血"占位。
2. **真按键未自动化验证**：输入走 `Keyboard.current`（`InputManager` 无公开读值 API），验证的是行为层；**手感必须人工试**。
3. **门客没有 HP/阵亡状态**：所以"补充减员"目前是闸门 + 占位日志，不能真正复活。
4. **修甲未做**：工程无护甲系统。
5. **失败判定 = 受控角色 hp 归零**（不再重生），比概念案的"全队倒下"更严格/更简单，待 W4 复核。
6. **扎营触发只有 C 键 + GM**，没有营地场景物件；"不耗时/不刷怪"是原型口径。
7. **结算面板列表无滚动**（只有 `RectMask2D` 裁剪），条目上限 8 时够用，超过会被裁。

## 4. 未验证项

3. 结算 `Save(3)` 的返回值未单独打印（Confirm 内无异常、槽位文件生成过）。

## 5. 已修复的关键缺陷（供复盘）

| 缺陷 | 根因 | 修法 |
| --- | --- | --- |
| 进局后 6 门客 / 50 敌人 | `EnterScene` 未清场 + `OnSceneCleared` 同步递归进入下一场景 | 进入即 `PurgeAllRuntimeObjects()`、清场改延迟一帧、清房判定去掉位置过滤 |
| 切场景后门客=0 | `EnterScene(next, Team)` 传的就是 `Team`，内部 `Team.Clear()` 先清空自己 | 先拷贝再清空 |
| 清房后不切场景 | `Purge` 销毁了 `RunEncounterTicker`，没人执行 `ProcessPendingScene` | ticker 不参与清理 + `EnsureTicker` 静态缓存 |
| 门客原地弹跳 | 跳的条件是"玩家在上方"且 `IsGrounded` 探不到地面 | 落地检测改胶囊底部 `BoxCast`；删掉该规则，改"贴正下方 + 短传送" |
| 结算面板看不见 | 进局隐藏 UI 时把 `UIRoot/Canvas` 的 `activeSelf` 也置 false | `Open()` 先 `RestoreAfterGameplay()` + 沿父链激活 |
| 面板按钮显示 key | `LocalizedText` 挂了 key 但表里没有 | 面板文案改纯中文，不挂 `LocalizedText` |
| 敌人摔死也给掉落 | `Die("掉落死亡")` 也走击杀掉落 | 掉落死亡跳过 `DropService`（防跳崖刷装备） |
