# `LoadingTable` 字段规格说明（读条轮播表）

> 状态：评审中
> Owner：策划
> 最后更新：2026-10-06
> 关联：`Story/03_配置表设计/01_配置表填写规范.md`、`Story/03_配置表设计/00_配置表清单.md`、`Story/03_配置表设计/02_配置表字段规格模板.md`、`Assets/Excel/Chaos_excel/LoadingTable_读条轮播表.xlsx`

> ⚠️ **本表最关键的一条设计事实（不是设计疏漏，请勿"修正"）**：
> **导出器只支持 12 个基础类型，没有 `Sprite`（也没有任何 Unity 资源类型）** —— 权威 = `ConfigManager.Convert` 的 `case` 列表：
> `int` `uint` `long` `ulong` `byte` `sbyte` `short` `ushort` `float` `double` `bool` `string`。
> 因此「**轮播图 `srcImg` 走配表**」在本工程**唯一可行的形态**是：
> **配表里存 `string` 资源路径（`Resources` 相对路径、不带扩展名），运行时由代码 `Resources.Load<Sprite>(path)` 加载**。
> 任何"在表里直接放 Sprite/图片对象"的想法都需要**程序先改导出器**（新增类型 + 改 `Convert` + 改 `ExportClass`），本阶段不做。
> 详见 `Story/03_配置表设计/01_配置表填写规范.md` §3.5。

| 行 | A | B | C | D | E | F |
| --- | --- | --- | --- | --- | --- | --- |
| 第 1 行 `类名` | `LoadingTable` | | | | | |
| 第 2 行 `是否读取` | `IsConfig` | | | | | |
| 第 3 行 中文备注 | 序号 | 轮播图资源路径 | 播放顺序 | 单张停留秒数 | 切换淡入淡出秒数 | 是否启用 |

> 第 6 行类型全部来自 12 类型白名单，且为**小写**。第 4 行属性名全部非空且唯一。

## 3. 字段清单（本表的权威字段定义）

| 列序 | 第 3 行 中文备注 | 第 4 行 属性名 | 第 5 行 端标记 | 第 6 行 类型 | 含义与取值 | 必填 | 默认值 | 关联表 / 关联字段 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| A | 序号 | `Id` | `client` | `uint` | 行唯一 ID，`1` 起递增 | 是 | — | — | **主键**，表内唯一 |
| B | 轮播图资源路径 | `srcImg` | `client` | `string` | **`Resources` 相对路径、不带扩展名**，如 `UI/Loading/Loading_01`（对应 `Assets/Resources/UI/Loading/Loading_01.png`） | 是 | `""` | — | **不能是 Sprite 类型**（导出器无此类型，见文首 ⚠️）；不得含英文逗号 / 英文双引号 / 换行 |
| C | 播放顺序 | `sort` | `client` | `uint` | 升序播放；建议从 `1` 起、**表内唯一**（重复时播放顺序不稳定） | 是 | `0` | — | 只影响顺序，不影响是否启用 |
| D | 单张停留秒数 | `showSeconds` | `client` | `float` | 单位**秒**；`>0` 为有效值，**`≤0` 时由代码取默认值** | 是 | `5` | — | 量纲必须与 `fadeSeconds` 一致（都用秒） |
| E | 切换淡入淡出秒数 | `fadeSeconds` | `client` | `float` | 单位**秒**；**`0` = 直接切换**（不淡入淡出） | 是 | `0.5` | — | 必须 `< showSeconds`，否则单张还没显示完就切走（见 §6 C5） |
| F | 是否启用 | `enable` | `client` | `bool` | `true` = 参与轮播；`false` = 保留在表里但不播放 | 是 | `true` | — | **不能留空**；可填 `true`/`false`、`1`/`0`、`是`/`否`（不区分大小写），导出为**裸值** `true`/`false` |

填写要求：

- 本表**没有外键**（不引用其他表），因此不涉及关联表校验。
- 「含义与取值」中的量纲（秒）必须写清，避免后人把 `showSeconds` 当成毫秒。

## 4. 键值 / 枚举字段对照表

> `enum` 仍不支持；"开关"直接用 `bool` 列。`bool` 取值只能填 `true`/`false`、`1`/`0`、`是`/`否`（不区分大小写），**不能留空** —— 详见规范 §3.3。

### 4.1 开关型字段（第 6 行类型写 `bool`）

> 导出后 Json 里是**裸值** `true` / `false`（**不加引号**）。

| 字段 | `true` 的含义 | `false` 的含义 |
| --- | --- | --- |
| `enable` | **参与轮播**（该张会被播放） | **停用**：保留在表里但不播放（方便临时下线某张图，不必删行） |

> 本次 3 行占位数据**特意用中文别名 `是`** 填写 —— 用于**端到端验证 T7 新增的 `bool` 归一化分支**（`Convert` 会把 `是` 归一化成裸值 `true`）。
> `是` / `true` / `1` 三种写法**完全等价**；`TRUE`、`True` 也合法（同样会被归一化成小写）。

### 4.2 枚举型字段

**本表无枚举字段。**（记录规则以备将来扩表：若将来要按"画幅 / 平台 / 场景类型"区分轮播图，**必须**用 `uint` + 数字↔含义对照表，不能用 `enum`。）

## 6. 数据约束与校验规则（策划侧约定）

> 导出器**不做任何校验**（规范 L5），以下规则靠策划人工把关 + 程序运行时兜底。

| # | 约束 | 违反后果 | 谁来把关 |
| --- | --- | --- | --- |
| C1 | `Id` 表内唯一、非空 | 运行时遍历不受影响，但排错与后续"按 ID 取图"会拿到重复行 | 策划 |
| C2 | `sort` 建议表内**唯一且为正整数** | 排序不稳定 → 轮播顺序随机变化 | 策划 |
| C3 | `srcImg` **非空**、**不带扩展名**、**`Resources` 相对路径**、不含英文逗号 / 双引号 / 换行 | 路径错 → 加载失败；含英文逗号 → **破坏整表 Json** | 策划（规范 §6.1） |
| C4 | `srcImg` 指向的资源**必须真实存在**于 `Assets/Resources/UI/Loading/`，且**导入类型是 Sprite** | `Resources.Load<Sprite>` 返回 `null` → 该张不显示（**不报错**，最容易被忽略） | 策划 + 程序 |
| C5 | `0 ≤ fadeSeconds < showSeconds`，且 `showSeconds > 0` | `fade ≥ show` 时图还没完全显示就被切走；`show ≤ 0` 落到代码默认值 | 策划 |
| C6 | 至少 **1 行** `enable=true` | 全部停用 → 加载界面无背景图（应回退纯色底，见 §8） | 策划 |
| C7 | 行数建议 **≤ 10** | 一轮播放时长 = `showSeconds × 行数`，行数过多会让"同一张图"很久才再出现 | 策划 |

## 7. UI 与表现要求（本表数据驱动的部分）

| 字段 | 影响的表现 | 具体要求 |
| --- | --- | --- |
| `srcImg` | **整屏背景图**（轮播主体） | 由代码 `Resources.Load<Sprite>(srcImg)` 加载；**整屏铺满**（保持比例 + 裁切或拉伸由表现规范定，`策划建议`：等比铺满 + 轻微缓慢缩放）。⚠️ 图片资源必须按 **Sprite** 导入 |
| `sort` | 播放顺序 | 升序；`enable=false` 的行先被过滤掉 |
| `showSeconds` | 单张停留时长 | 单位秒；`策划建议` 3~8 秒（过长会让玩家以为卡住，过短像闪烁） |
| `fadeSeconds` | 两张之间的过渡 | `0` = 硬切；`策划建议` 0.3~1.0 秒淡入淡出 |
| `enable` | 是否参与轮播 | 停用行不播放；用于临时下线一张图而**不删行**（保留 `Id` 稳定） |

**边界说明**：**本表只控制"背景轮播图"，不控制进度条**。进度条与场景跳转由加载逻辑决定（T13 落地方案），
本表不提供任何进度相关字段。

## 8. 边界与异常

| 场景 | 期望行为 |
| --- | --- |
| 表里没有该 `Id` | **不适用**：本表是**全表遍历**（不按 Id 查单条），不存在"查不到 Id"的路径 |
| `srcImg` 指向的资源不存在 / 不是 Sprite | `Resources.Load` 返回 `null` → **跳过该张**并记一条 warning；若**全部**加载失败 → 回退纯色底背景（不阻塞加载流程） |
| `enable` 全部为 `false`，或表被删到 **0 行** | 加载界面**无轮播图**：只显示纯色底 + 进度条；**不得报错、不得卡住** |
| 只有 **1 行** `enable=true` | **不轮播**，静止显示该图（不闪烁、不重复淡入淡出） |
| `showSeconds ≤ 0` | 取**默认停留 5 秒**（架构师已答复，见 §9 Q2） |
| `fadeSeconds = 0` | 直接切换，无过渡 |
| `fadeSeconds ≥ showSeconds` | 违反 C5；**程序按 `fade = 0.5s` 兜底并记 Warn**（见 §9 Q2），避免"图没显示完就切走" |
| 轮播图尚未加载完 | 先显示纯色底，加载完成后再显示（避免白屏/黑屏闪烁） |
| 数据行数 > 10 | 不报错，但一轮播放时间过长；建议按 C7 控制 |
