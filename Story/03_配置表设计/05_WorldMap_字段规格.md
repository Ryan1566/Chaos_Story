# `WorldMap` 字段规格说明（世界观地图表）

> 状态：评审中
> Owner：策划
> 最后更新：2026-10-12
> 关联：`Story/02_系统策划/02_局外世界观地图系统.md`、`Story/03_配置表设计/06_WorldFaction_字段规格.md`、`Story/03_配置表设计/01_配置表填写规范.md`、`Story/03_配置表设计/02_配置表字段规格模板.md`、`Story/02_系统策划/03_地点表与兴趣点表_接口约定.md`、`Assets/Excel/Chaos_excel/WorldMap_世界观地图表.xlsx`

> ⚠️ **本表由「地图绘制工具」产出，不是策划手填**（工具读可自定义的源图 → 摆点 → 导出 7 行表头格式的 `.xlsx`）。
> 策划负责**规格与验收**；工具产出后**不要手工改这张表**（改了就和工具的工程不一致，下次重导会被覆盖）。
> 产出链路与工具职责见 `Story/02_系统策划/02_局外世界观地图系统.md` §7。

> **两条硬约束（踩过的坑，必须先读）**
> 1. **顶层目录 `Assets/Excel/Chaos_excel/` 里任何一张表都必须 ≥ 1 行数据**（只有表头 = 空表）。只有表头 → 该表无导出项；**页签完全空白 → 抛异常并中断整批导出**，其后所有表都不导出。
> 2. **顶层同英文前缀只能有一张表**：`WorldMap_B.xlsx` 与 `WorldMap_C.xlsx` 会导出**同一个** `WorldMapConfig` 并**静默互相覆盖**（不报错）。本表在顶层**只有一张**：`WorldMap_世界观地图表.xlsx`。

## 3. 字段清单（逐列：本表的权威字段定义）

| 列 | 第 3 行 中文备注 | 第 4 行 属性名 | 第 5 行 端标记 | 第 6 行 类型 | 含义与取值 | 取值范围 | 示例 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| A | 序号 | `Index` | `client` | `uint` | 行序号，**表内唯一**；由工具生成（建议 1 起连续） | ≥1 的整数 | `1` |
| B | 地图ID | `MapId` | `client` | `uint` | 该行属于哪张底图。**当前只有 `1` = 天下中原**；多图预留 | 1（当前唯一） | `1` |
| C | 条目类别 | `Kind` | `client` | `uint` | `1` = 固定地点；`2` = 兴趣点；**`3+` 预留**（见 §4.2） | 1 / 2 | `1` |
| D | 地点类型 | `Type` | `client` | `uint` | 分类值：`Kind=1` 时 = **地点表**的分类；`Kind=2` 时 = **兴趣点表**的分类。**具体值域由那两张表定义**（本次未建表） | 由目标表定义 | `1` |

| G | 纵坐标 | `Y` | `client` | `float` | **归一化纵坐标**：**自底图下边界向上**，`0` = 最下、`1` = 最上。⚠️ **Y 向上**（与图片像素原点方向相反，见 §6 C4） | `0 ~ 1` | `0.8088` |
| H | 图标缩放 | `Scale` | `client` | `float` | 该点图标的缩放倍数；**默认 1** | >0（建议 0.5~2） | `1` |

## 4. 键值 / 枚举字段对照表

### 4.1 开关型字段（`bool`）

> 导出后 Json 里是**裸值** `true` / `false`（**不加引号**）。
> **可填**：`true`/`false`、`1`/`0`、`是`/`否`（**不区分大小写**，前后空格自动忽略）。
> **不能留空**；`yes`/`y`/`no`/`n`/`开`/`关` 及任何其它文本**一律抛异常**，且错误会**中断整批导出**。

| 字段 | `true` 的含义 | `false` 的含义 |
| --- | --- | --- |
| `Enable` | 该点位**显示** | 该点位**不显示**（保留在表里，便于临时下线而不删行） |

### 4.2 枚举型字段（`uint` + 对照表；**导出器不支持 `enum`**）

| 字段 | 值 | 含义 | 备注 |
| --- | --- | --- | --- |
| `Kind` | 1 | 固定地点 | 内容查**地点表** |
| | 2 | 兴趣点 | 内容查**兴趣点表** |
| | 3+ | **预留** | 将来若新增类别（如"势力中心""事件点"），**先加对照表再使用**；⚠️ 新增类别属于接口变更，需同步 `03_地点表与兴趣点表_接口约定.md` 与运行时映射 |
| `MapId` | 1 | 天下中原（`Map_tianxia_zhongyuan.png`，4096×3138） | 多图预留 |
| `Type` | — | **值域由地点表 / 兴趣点表定义** | 本表**不**定义分类含义，避免两处定义漂移 |
| `Layer` | 0 | 默认层级 | 数值越大越靠上 |

## 6. 数据约束与校验规则

> 导出器**不做任何校验**（数值列填文字也不报错，会直接产出非法 Json）。以下约束由**工具在导出前校验** + 策划人工把关。

| # | 约束 | 违反后果 | 谁来把关 |
| --- | --- | --- | --- |
| C1 | `Index` 表内唯一、非空 | 排查困难；运行时遍历不受影响 | 工具 |
| C2 | `(Kind, Type, RefId)` **不建议出现多行** | 同一地点画两个图标 | 工具（§14 A5 of 系统文档） |
| C3 | `X`、`Y` ∈ `[0, 1]` | 点位跑到图外或被裁掉 | 工具 |
| C4 | **Y 向上**：像素 → 归一化用 `X = px / 图宽`、`Y = 1 - py / 图高`（`px`/`py` 以图片**左上角**为原点） | **算错 = 上下镜像**，点位与势力范围全错（最危险的一处） | 工具 + 程序（§9 Q1） |
| C5 | `Scale > 0`（建议 0.5~2） | 0 或负数 → 图标不可见或反向 | 工具 |
| C6 | `Layer` 为整数（建议 0~99） | 层序异常但不报错 | 工具 |
| C7 | `Enable` **逐行填满**，不得留空 | 空值 → 导出期抛异常并**中断整批导出** | 工具 + 策划 |
| C8 | `MapId` 当前必须为 `1` | 指向不存在的底图 → 该点无处显示 | 工具 |
| C9 | 字符串单元格（本表当前没有，预留）**禁英文逗号 / 英文双引号 / 换行** | 英文逗号会**破坏整表 Json** | 策划 |

## 7. UI 与表现要求（本表数据驱动的部分）

| 字段 | 影响的表现 | 具体要求 |
| --- | --- | --- |
| `X` / `Y` | 点位在底图上的位置 | 归一化坐标映射到地图区域；图标**中心对齐**该点 |
| `Kind` / `Type` / `RefId` | 点位图标样式与点击行为 | 图标资源与详情面板由**地点表 / 兴趣点表**决定（本次占位）；MVP 先只报出三元组 |
| `Scale` | 图标大小 | 与底图缩放无关；建议在 0.5~2 之间 |
| `Layer` | 重叠时的上下关系 | 数值大的在上；绘制层次：底图 → 势力多边形 → 固定地点 → 兴趣点（同 `Layer` 时） |
| `Enable` | 是否显示 | `false` 的行不绘制 |

> 系统级表现要求（底图铺满、势力半透明、时期切换过渡等）见 `Story/02_系统策划/02_局外世界观地图系统.md` §10。

## 8. 边界与异常

| 场景 | 期望行为 |
| --- | --- |
| 本表 **0 行 / 全部 `Enable = false`** | 地图只显示底图，无点位；**不报错** |
| `X` / `Y` 越界 | 运行时不校验 → 点位画出边界外或被裁掉；**工具应在导出前拦截**（C3） |
| `RefId` 在地点表 / 兴趣点表里**不存在** | **导出器不校验外键、运行时不报错** → 点位缺图标/详情；由工具与策划人工把关（§9 Q5） |
| `Kind` 出现 **3+**（预留值） | 运行时**未知类别** → 跳过该行并记 warning（不得崩溃） |
| `Kind = 2` 但兴趣点表尚未建 | MVP 允许：只画出占位图标，点击只报三元组（`02_局外世界观地图系统.md` §11） |
| Json 缺失 / 底图缺失 | 降级为"只有底图"/纯色底 + warning，**不阻塞进入局外** |
