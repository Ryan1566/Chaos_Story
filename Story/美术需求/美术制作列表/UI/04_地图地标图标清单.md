## 1. 规格

### 1.1 尺寸：从代码实测推导，不照抄既有文件尺寸

| 用途 | 代码实测显示尺寸（UI 单位） | 依据 | @1920 物理 px | @1366 物理 px | 1× 画布 | 2× 画布 |
|---|---|---|---|---|---|---|
| 大地图 · 普通地标 | 根节点 **30**／剪影绘制区 **22** | `WorldLocationsView.cs:55`（`NormalSize = 30f`）、`:296`（`sizeDelta = NormalSize`）、`:311-312`（Glyph 四边 inset 4 → 30−8） | 30／22 | 21.3／15.6 | **24** | **48** |
| 大地图 · 主城（Capital） | 根节点 **38**／剪影绘制区 **30** | `WorldLocationsView.cs:54`（`CapitalSize = 38f`）、`:368`（按 Kind 取值） | 38／30 | 27.0／21.3 | **32** | **64** |
| 局内地图节点 · 卡面图标 | **无实测值**（该组零引用，见 §6.3） | 卡片 234×176、九宫格 Border 24（`02` §2.11）→ 内容区 186×128 | — | — | **64** | **128** |
| 配套 · 小地图框 | 190×190 | `02` §5.4 | — | — | 190（单档） | — |

**取整过程（必须照此写进验收单）**

- 22 → 向上取 4 的倍数 = **24**；2× = **48**
- 30 → 向上取 4 的倍数 = **32**；2× = **64**
- 局内 64 → 已是 4 的倍数；2× = **128**

**为什么大地图要 2×**：标记在缩放时会整体放大——悬停 ×1.35、选中 ×1.6（`WorldMapPointIcon.cs:15-16`、`:71-72`）。22px 剪影选中时画到 **35.2px**、主城画到 **48px**，只有 2× 素材够这档；1× 素材放大 1.6 倍后每个源像素要摊到 1.6 个屏幕像素，边缘必软。地图本体缩放不影响图标尺寸：`WorldLocationsView.cs:370` 用 `point.scale = 1/max(1,zoom)` 反向抵消，图标在 zoom 1~6 全程屏幕尺寸恒定，所以**只需要 1×/2× 两档位图，不需要为缩放另出图**。

**局内 64px 的推导（不是实测，必须标注）**：卡片 234×176、Border 24 → 内容区 186×128；图标取内容区高度的 50% = 64px，剩余 64px 留给 TMP 名称与规则行。该组当前在工程内零引用（§6.3），量不出真实呈现尺寸，接图时必须回测。

### 1.2 画布与构图

| 项 | 规格 |
|---|---|
| 画布 | **严格正方形**，边长按 §1.1（24/32/48/64/128），透明背景 |
| 主体占比 | 主体外接框**最长边 = 画布 80%**（容差 ±2%）。短边按原始轮廓比例，**不许为了凑方框把宽扁物件拉高** |
| 主体定位 | 外接框几何中心与画布中心重合，**偏差 ≤1px（2× 尺度）** |
| 留白 | 四周 ≥10% 画布（24px 上 ≥2.4px、48px 上 ≥4.8px），保证描边与抗锯齿不被裁 |
| 母版 | 先在 **256×256** 母版上画一张，再**等比缩**出 1×/2× 两档（同一张图缩档，不重画、不改构图）。母版最长边 ≈ **205px（80%±2%）** |
| 九宫格 | **Border = 0,0,0,0**（纯图形件，禁止拉伸） |

**统一视觉重量的判定**：以「最长边占画布 80%」为唯一标准，不看面积。现有 12 张里有 8 张最长边在 82%~88%、最短的 capital 与 easter_egg 只有 78.1%，同屏时大小肉眼可见不齐（§6.1 逐张列出）。

### 1.3 单色、明暗与描边（配色见风格提示词）

| 项 | 规格 |
|---|---|
| 剪影色 | **单色**：一张图只用一种不透明色，不得自带第二种颜色或自带底板。具体色值由风格提示词决定 |
| 局内节点明暗 | 必须用**浅色剪影**：局内卡底实测为深色 `(42,36,29)`，深色剪影对照只有 **1.01:1**，等于看不见；大地图反之用深色剪影压浅色底板 |
| 镂空 | 内部细节用**透明负空间**表达（现有 12 张即此做法），不画白色/浅色填充 |
| 渐变 / 发光 / 投影 | **禁止**。1× 上只有 22px 的图形放不下渐变，只会脏 |
| 外轮廓描边 | **不使用独立外描边**——形状由实心块面的边界构成，细描边在 1366 下只有 0.7px，必糊 |
| 内部分界描边 | 统一 **2× 上 2px**（= 1× 上 1px；按普通地标 48→256 母版折算 = 母版 10.7px），用于檐口、洞口内沿、田埂等内外分界 |
| 最小负空间 | **2× 上 ≥4px**（= 256 母版 ≥21px）。小于这个宽度的镂空在 1× 上会合缝 |
| 抗锯齿 | 边缘 1px 过渡即可，禁止羽化到 2px 以上 |

## 3. 禁止文字与符号（**强制条款，违反即整批退回**）

**3.1 图标内不得出现任何文字形态。**

| 类别 | 禁止内容 |
|---|---|
| 文字 | 汉字、假名、谚文、拉丁字母、西里尔字母、阿拉伯字母，以及任何真实或虚构文字体系（含甲骨、金文、小篆、隶书、楷书字形） |
| 数字 | 0-9、罗马数字（Ⅰ Ⅱ Ⅲ）、算筹、计数刻痕、序号 |
| 标点 | `，。、；：！？（）【】《》""''…—` 与 `. , ; : ! ? ( ) [ ] { } " ' / \` |
| 符号 | `× ✕ ✓ ✔ + − ± ← → ↑ ↓ ↵ ★ ☆ ￥ $ % # @ & * ~ § † ‡ ● ▲ ◆ ○ □` 及任何字符形态 |
| 伪文字 | AI 生图常见的"像字不是字"的乱码、扭曲纹章字母、篆刻伪字、符文、铭文、字母浮雕 |
| 地图专属 | **地标图标不得自带编号**（1~12、Ⅰ~Ⅻ、甲/乙/丙）、不得自带星级表示主城等级、不得自带货币符号表示贸易 |

**3.2 语义只能由「剪影 + 形状 + 配色」三者承担，其余一律不许。**
不许用文字缩写（`铁` `盐` `市`）、不许用字母区分（`F` `M` `T`）、不许用符号提示（`?` 传闻、`!` 任务、`×` 未解锁）。

**3.3 天然靠文字区分的类型，一律改图形隐喻：**

| 概念 | ❌ 禁用 | ✅ 允许 |
|---|---|---|
| 铁匠 | "铁"字 / "F" | 铁砧 + 锤 |
| 酒馆 | "酒" / "T" | 酒壶 + 杯（壶口留负空间） |
| 集市 | "市" | 单坡棚 + 立柱 + 柜台（= `market_town`） |
| 盐场 | "盐" | 田格 + 卤池（= `saltworks`） |
| 传闻 | "?" / "闻" | 竹简双联（= `rumor`） |
| 任务 | "!" / "任" | 挂木牌（= `task`） |
| 未解锁 | "×" / 锁芯上的"锁"字 | 斜纹暗罩（= `G-HUD-11`） |

**3.4 判定方法（验收必做）**
1. 把成品缩到 **24px** 看 3 秒：能读出任何字或符号 = 不合格。
2. 跑一次 OCR（任意引擎）：返回 **0 个字符** = 通过。
3. 缩到 24px 后仍能说出"这是什么地点" = 通过；说不出来 = 剪影不合格（不是加字，是改形）。

**3.5 现有工程的错误示范（不要再犯）**：图标缺失时 `WorldLocationsView.cs:474-503` 会在方块里写汉字（城/市/营/林/矿/石/盐/洞/迹/见/闻/事），`QA/WorldLocations/map-market-1920.png` 就是这个样子。**这是缺图兜底，不是设计**——本轮补齐图标后必须一次都不出现。

## 5. 验收

### 5.1 尺寸与最小可辨识

| 场景 | 普通地标 | 主城 | 局内节点 |
|---|---|---|---|
| 1920×1080 绘制区 | 22px（墨迹 ≈17.6px） | 30px（墨迹 ≈24px） | 64px |
| 1366×768 绘制区 | 15.6px（墨迹 ≈12.5px） | 21.3px（墨迹 ≈17px） | 45.5px |
| 悬停时（×1.35） | 29.7 / 21.1px | 40.5 / 28.8px | — |
| 选中时（×1.6） | 35.2 / 25px | 48 / 34.1px | — |

**判定**：1366 下 12.5px 墨迹是硬下限——剪影必须**实心块面**，任何细于 1px（1× 尺度）的凸起都会被抹掉。所以 §1.3 才禁止独立外描边。

### 5.2 对比度（实测值，必须 ≥4.5:1）

| 前景 / 背景 | 对比度 | 结论 |
|---|---|---|
| 深色剪影 / 浅色底板（合成后） | **9.01 : 1** | ✅ |
| 深色剪影 / 主城暖浅底板（合成） | **9.70 : 1** | ✅ |
| 深色剪影 / 选中态最亮底板（合成） | **7.03 : 1** | ✅ 选中态剪影仍清晰 |
| 浅色剪影 / 局内深色卡底 | **10.71 : 1** | ✅ |
| 深色剪影 / **底图直接压上去**（无底板，取底图中等亮度区） | **2.85 : 1** | ❌ 这就是「底板不得省」的量化理由 |
| 灰化剪影 / 深色底（未解锁） | **4.07 : 1** | ✅ 弱化但仍可辨 |

### 5.3 相邻图标不粘连（配置实测；素材侧只做缓解，根治靠代码）

按 `WorldLocationTable_Location.json` 62 个点位的 X/Y（0~1）换算到 IconLayer 1409.71×1080：

| 间距 | 对数 | 结论 |
|---|---|---|
| < 12px | **8 对** | 必粘连 |
| < 22px | **21 对** | 必粘连（22px = 一个图标） |
| < 30px | 26 对 | 会贴边 |
| 最近一对 | **1.9px**（1009 与 4006） | 完全重叠 |

→ **素材验收要求**：剪影墨迹不得超出画布 80%，保证两个图标最小外接框之间还有 ≥10% 空隙（24px 上 = 2.4px）。这能把"21 对粘连"压到"只剩 <12px 的 8 对"，剩下的必须靠运行时避让（§6.3 列入代码侧缺口）。

### 5.4 缩到 1× 后剪影仍可辨

- 23 类两两对比（大地图 17 + 局内 6），在 24px 下由 **≥8/10 人** 认出才算通过。
- 易混对必须逐对确认：`market_town` vs `MapNode_Shop`、`iron_mine` vs `cave`、`quarry` vs `ruins`、`task` vs `side_quest`、`temporary` vs `tribe`。
- 灰度打印一遍：只有明度差、没有颜色差时仍能区分（5.2 的对比度已保证这一点）。

### 5.5 验收 checklist

- [ ] 23 类 × 2 档 = 46 个文件齐全，文件名与 IconKey 完全一致
- [ ] 每张透明背景、PNG-32、直通 Alpha、无白边、无杂色、无半透明底
- [ ] 最长边 80%±2%，中心偏差 ≤1px@2×
- [ ] 素材内无文字/数字/符号/伪文字（OCR 返回 0 字符）
- [ ] 1× 档 24px 下剪影可辨（§5.4）
- [ ] 大地图用深色剪影、局内用浅色剪影，单张图无第三色
- [ ] 导入设置：Full Rect、Compression None、Mipmap 关、Border 0
- [ ] 不占用势力 9 色
- [ ] 同屏 1920×1080 与 1366×768 各截一张，与 `QA/RunCompletion/map-icons.png` 对比不"变小变糊"
