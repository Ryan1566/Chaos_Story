## 1. 批量规则

- **每批默认 1–2 张新母版。** 全屏大面板、特殊轮廓与首次尝试的长条每批 1 张。低复杂度的同族部件最多 2 张。由已通过的同一母版派生状态时，每批最多 3 张成品，逐态对齐。
- 每次处理一批并核对结果。连续生产时按清单顺序推进，逐批记录。每次生成调用画一个完整元件。母版需要修正时，先记录失败原因，再决定重出、清边或分件。纯状态派生可用同一底图与蒙版编辑，并在交付记录里标明来源。
- 三版概念图作风格锚点，正式元件采用同一组暖灰米纸、墨褐外框、暗朱内线和受限角纹。状态间保留相同轮廓、裁切、线宽、Border 与 pivot。标题、文字和数值由游戏排版。
- 批次状态依次记录为**待生成、候选待修或文件通过、待接入、实机通过**。依赖母版的批次等该母版文件通过后开始。生成件、母版、清边导出件、实机截图分别登记。版本变更时保留可回查的原生来源与失败记录。

## 3. 交付与验收

1. **文件检查**记录原生尺寸、实际主体框、成品尺寸、状态、裁切和透明边。浅深底检查白晕、残纸与低 Alpha 散点。原生画布小或比例偏差时记录实测，等比导出不得拉扁，也不得靠补大透明画布达标。
2. **九宫格与套准**以 02 的成品 Border 画切线，检查主体落在固定边带、角纹无跨线。状态切换共用注册框。需要分件重组时记录部件来源和接入方式。
3. **实机记录**用真实入口检查 1920×1080 与 2560×1440。记录最终导入像素、Image 类型和状态截图。当前只完成文件检查时，实机栏写待验。
4. 每批只更新本表相关状态，并在下方追加候选版本、来源、调用次数、实测值和处理结论。待修件不作为下一批的母版或正式替换资源。
