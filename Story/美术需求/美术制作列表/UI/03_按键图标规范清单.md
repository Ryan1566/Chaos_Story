# 03 · 按键图标规范清单

> 适用工程：Project_Chaos（Unity 2022.3.57f1c2，2D）。基准分辨率 1920×1080，`CanvasScaler = ScaleWithScreenSize / matchWidthOrHeight = 0.5`。
> 本文档是**设置界面输入按键图标（Input Icon）的唯一生产清单**。执行方（美术 agent / 外包）按本清单逐行出图即可，不需要再看代码。
> 配套文档：`01_美术执行标准与首轮需求.md`（风格基准）、`02_UI素材替换总清单.md`（整包 UI 换皮）、`04_地图地标图标清单.md`（地图地标 icon）。
> 数据来源（全部为代码/配置实测，非推测）：`Assets/Scripts/Runtime/3C/Control/InputManager/KeyIconMap.cs`、`Assets/Scripts/Editor/InputIcon/IconNaming.cs`、`Assets/Scripts/Editor/ArtPipeline/IconAtlasBuilder.cs`、`Assets/Scripts/Editor/ArtPipeline/IconImportPostprocessor.cs`、`Assets/Scripts/Runtime/MVP/View/SettingsPage/KeybindBindingsPage.cs`、`Assets/Scripts/Runtime/3C/Control/InputManager/InputManager.cs`、`Assets/Scripts/Runtime/3C/Control/InputManager/InputManager.Gameplay.cs`、`Assets/Scripts/Runtime/GameBase/SettingRows/KeyIconText.cs`、`Assets/Scripts/Runtime/GameBase/SettingsManager/SettingIds.cs`、`Assets/Resources/Input/ChaosInputActions.inputactions`、`Assets/Prefabs/UI/SettingRows/SettingRow_Keybind.prefab`、`Assets/Resources/Data/Input/KeyIconMap.asset`。
> 现有库：`Assets/Art/Input_icon/` 下 `keyboard&mouse` 241 张、`ps` 104 张、`xbox` 91 张，共 **436 张，全部 64×64**，每种键 `xxx.png`（Filled）+ `xxx_outline.png`（Outline）两版。

## 0. 这份文档约束的四个事实（先说清楚，否则出图一定错）

| 事实 | 实测依据 | 对出图的直接约束 |
|---|---|---|
| 图标画在**设置行键格内 `KeyText` 的 `Icon` 子节点**上（Image，`m_PreserveAspect: 1`，锚点 0,0–1,1，`sprite` 由运行时写入，prefab 里是 `null`） | `SettingRow_Keybind.prefab`：Icon 的 Image `preserveAspect=1`、`sprite={fileID:0}`、`raycastTarget=0` | 图标按**自身长宽比**适配键格，不会被拉扁 → 2:1 宽键图能正确显示；**不得**依赖拉伸补形 |
| 键格实际显示区 ≈ **308×73 px**（键格锚点 0.29–0.51 / 0.12–0.88，行 1400×96）；方键在格内按高度对齐 ≈ **73×73**，宽键 ≈ **146×73** | 同上 + 用户实测 | 1× 图（64px）会被放大 **1.14×** 显示；2× 图（128px）是缩小显示 → **2× 才是最终清晰度档** |
| 图标颜色 = `Image.color = KeyIconMap.tint`（**乘法染色**，非覆盖）；`KeyIconText.ApplyIcon` 里 `icon.color = _iconColor` | `KeyIconText.cs:136-143`、`KeyIconMap.GetIconColor` | 图必须是**纯白 RGB + alpha 层次**，所有深浅对比只能写在 **alpha** 上（详见 §1.3） |
| 同一格「文字 / 图标」**互斥**：有图标就把 TMP 关掉（`text.enabled = !_showIcon`） | `KeyIconText.cs:106-110`、`123-133` | 空键帽图标必须与 TMP 键名**叠加**才有意义 → 需程序把 `KeyIconText` 改成叠加模式（见 §8 缺口 G-3）；本文档按「空键帽 + TMP 叠加」出图 |

## 1. 统一输出规格（本文档核心）

### 1.1 尺寸矩阵（唯一权威）

| 类 | 1× 画布 | 2× 画布 | 四周透明留白（1× / 2×） | 图形安全区（1× / 2×） | 适用行 |
|---|---|---|---|---|---|
| **方键**（绝大多数） | **64×64** | **128×128** | 4px / 8px | 56×56 / 112×112 | 字母、数字、F 键、标点、Delete/Insert/Home/End/PgUp/PgDn、方向键、鼠标、面键、摇杆、方向键簇 |
| **宽键 2:1** | **128×64** | **256×128** | 4px / 8px | 120×56 / 240×112 | Space、Tab、Shift、Ctrl、Alt、Win、CapsLock、Enter、Backspace、Return、Command、Option、手柄扳机 L1/L2/R1/R2 |
| **整机图例** | 64×64 | 128×128 | 4px / 8px | 56×56 / 112×112 | 键鼠页签（整只鼠标）、PS 页签、Xbox 页签 |

- 1× 必须**逐像素**等于上表；2× 必须等于 1× 的**整数 2 倍**，不允许 1.5×/3×/非等比。
- **画布尺寸即交付尺寸**，不得自行放大或缩小；不得出 32×32 / 96×96 之类中间尺寸。
- 宽键只允许 2:1。**没有 3:1 / 6.25:1 的物理键宽**：图标是「视觉重量单位」，不是键位图（见 §1.2 理由）。

### 1.2 键帽几何参数（两套风格共用同一套轮廓）

| 参数 | 1× | 2× | 说明 |
|---|---|---|---|
| 键帽外形 | 圆角矩形，方键 56×56，宽键 120×56，居中 | 112×112 / 240×112 | 外形**不得**碰到 64/128 画布边 |
| 圆角半径 R | 12px | 24px | 四角同值，不允许只圆上面两角 |
| 描边线宽 | **4px 恒定** | 8px 恒定 | 所有键、所有部位同一线宽（**无线宽差**）；不得用 2px 细线凑精细 |
| 描边生长方向 | 向内（外缘 = 键帽外缘） | 同 | Filled 与 Outline 的外缘必须重合，见 §6-4 |
| 内区留白 | 键帽内再缩 10px | 缩 20px | 内区是 TMP 键名叠加区，**不得**画任何图形（除 §3 允许的方向三角/阶梯） |
| 高光 / 投影 / 外发光 | **禁止** | **禁止** | 无 drop shadow、无 glow、无 inner shadow、无渐变光晕 |
| 底面 | 完全透明（alpha=0） | 同 | 除键帽轮廓内的填充/描边外，画布全透明 |

> 为什么宽键只做 2:1：`Icon` 是 `preserveAspect` 的，若按真实键宽（Space 6.25:1）出图，格内会被压到 ~12px 高，与方键的视觉重量差 6 倍，一排键帽会一大一小。2:1 是「宽键」与「方键」在同一行里仍可辨、重量仍接近的折中值。

### 1.3 颜色与 alpha 语法（**按此出图，否则接入即发黑/发白**）

运行时是**乘法染色**：`Image.color = tint`，最终像素 = 图 RGB × tint。图里画什么色都会被乘掉，**唯一可控的层次是 alpha**。

| 项 | 规定值 | 说明 |
|---|---|---|
| 图 RGB | **一律 (255,255,255) 纯白** | 例外只有 Color 风格面键（§1.4），且必须勾 `rawColor=1` 免染色 |
| Filled 键帽底 | 白，**alpha = 1.0** | 实心；乘以 tint 后即为界面上的键帽底色（深） |
| Filled 内区几何（无字） | 白，**alpha = 0.30** | 与底叠加后比底浅一档 → 这就是「深色底 + 浅色几何」的落地写法（浅色来自透出下层，不是画灰色） |
| Outline 描边 | 白，**alpha = 1.0**；内部 **alpha = 0** | 纯描边，内部完全透明 |
| 抗锯齿 | 边缘 1px 过渡（alpha 渐变） | 不得 3px 以上柔化，不得羽化 |
| 半透明范围 | 只允许 0 / 0.30 / 1.0 三档 | 不做出 0.5、0.7 的中间灰（会导致一排键帽深浅不齐） |

**染色取值的现状（必须知道）**：`KeyIconMap.tint` 代码默认是 `(0.1, 0.1, 0.1, 1)` 深灰，但 `Assets/Resources/Data/Input/KeyIconMap.asset` 里序列化的实际值是 `{r:1, g:1, b:1, a:1}` **纯白**。纯白 × 纯白 = 纯白，图标在白底键格（`KeyButton` 底图 `m_Color = (1,1,1,0.95)`）上会**看不见**。这是资产配置问题，不是出图问题；出图按「纯白 + alpha 层次」即可同时兼容两种 tint（白 × 任意色 = 该色），并把此项列入 §8 待程序确认。

### 1.4 三套风格（代码里的枚举就是三套）

| 风格 | 文件名规则 | 外观 | 用途 |
|---|---|---|---|
| `Filled = 0`（默认） | `xxx.png`（无后缀） | 实心键帽 + 内区浅色几何 | **设置界面主用**（`KeyIconMap.style = Filled`，实测资产值 `style: 0`） |
| `Outline = 1` | `xxx_outline.png` | 纯描边、内部透明、与 Filled 外缘重合 | 键位冲突提示、未绑定态、`G-CTRL-09` 语境 |
| `Color = 2` | 名字中部带 `_color_`，如 `playstation_button_color_cross.png` | 保留原始彩色（PS 面键 / Xbox A B X Y） | 可选；接入时必须 `rawColor=1`，否则被乘成近黑 |

- 每一条清单一律**同时交 Filled + Outline 两版**（约 2 倍文件量），除非该行备注写「只交 Filled」。
- Outline 不是「细一号的 Filled」：外形、圆角、内区留白数值**完全一致**，只是把填充换成 4px 描边。
- `Color` 风格**不单列条目**，作为面键的可选变体（PS ○×□△ 4 个、Xbox A/B/X/Y 4 个，共 8 个 token × 2 版），见 §4.3 / §4.4 备注。

### 1.5 格式与导入设置

| 项 | 规定 |
|---|---|
| 格式 | **PNG-32，直通 Alpha（Straight Alpha）**，不用 Premultiplied |
| 色彩空间 | sRGB；RGB 通道除 Color 风格外必须全为 255 |
| 背景 | 完全透明，**无背景色块、无底衬、无边框外溢** |
| 内嵌 | 不嵌 ICC / 不嵌缩略图 / 不带元数据块（控制体积） |
| 导入（工程侧已固化的设置，出图对齐即可） | `textureType = Sprite`、`spritePixelsPerUnit = 100`、`SpriteMeshType.FullRect`、`mipmapEnabled = false`、`alphaIsTransparency = true`、`npotScale = None`、`filterMode = Bilinear`、`wrapMode = Clamp`、crunch 压缩开 |
| ⚠ 硬上限 | `IconImportPostprocessor` 写死 `maxTextureSize = 128`。**2× 方键 128×128 刚好不被降采样；2× 宽键 256×128 会被降采样成 128×64**。出 2× 宽键前必须先让程序把该上限提到 256（见 §8 缺口 G-2），否则 2× 白出 |

### 1.6 目录与命名（命名错了就接入不了，逐条对齐 `IconNaming.TryParse`）

**目录即设备归属**（`IconNaming` 以目录决定 family，不看文件名）：

| 目录 | family | 图标前缀 | 本文档使用 |
|---|---|---|---|
| `Assets/Art/Input_icon/keyboard&mouse/` | `Keyboard` | `keyboard_` / `mouse_` | 键盘 106 + 鼠标 13 |
| `Assets/Art/Input_icon/xbox/` | `Xbox` | `xbox_` / `controller_` | Xbox 59 |
| `Assets/Art/Input_icon/ps/` | `PlayStation` | `playstation` / `controller_` | PlayStation 62 |

**文件名解析顺序（必须按此顺序构造名字，否则解析错风格/变体）**：

1. 去掉尾部 `_outline` → `style = Outline`；
2. 去掉尾部 `_icon_alternative` / `_alternative` / `_icon` → 变体标记（`Variant.GlyphAlternative / Alternative / Glyph`）；
3. 去掉头部 `keyboard_` / `mouse_` / `xbox_` / `playstation` / `controller_`；
4. 处理中部的 `_color_` → `style = Color`，并从 token 中删掉 `color_`（`button_color_cross` → `button_cross`）。

即完整命名：`<前缀>_<token>[_icon | _alternative | _icon_alternative][_outline].png`，Color 版为 `<前缀>_<token 前半>_color_<token 后半>.png`。

**本文档只产出 Plain 版**（不带 `_icon` / `_alternative` 后缀）：`KeyIconMap.preferGlyphVariant = true` 的挑选顺序是 Glyph(0) → Plain(1) → Alternative(2)，库中没有 Glyph 版时会自动回退 Plain，不需要改代码；但**库里现存的 7 个 `_icon` 旧变体必须替换或删除**（`keyboard_space_icon`、`keyboard_tab_icon`、`keyboard_tab_icon_alternative`、`keyboard_backspace_icon`、`keyboard_backspace_icon_alternative`、`keyboard_shift_icon`、`keyboard_capslock_icon`），否则它们会被优先选中，新图白画（见 §8 缺口 G-5）。

**别名 token（不单独出图，直接复用主 token 的文件）**：`return→enter`、`option→alt`、`command→win`、`apostrophe→quote`、`tilde→backquote`、`slash_forward→slash`、`mouse`（裸名）→ 整机图例。这些由 `IconNaming.KeyboardRows` 的 rank/别名机制覆盖，出重复图只会让图集变胖。

### 1.7 图集与体积预算

| 项 | 数值 | 说明 |
|---|---|---|
| 图集 | `IconAtlas_Input.spriteatlas`，`MaxTextureSize = 2048`，`padding = 4`，`blockOffset = 1`，`enableAlphaDilation = true`，`enableRotation = false`，`enableTightPacking = false`，`includeInBuild = true` | `IconAtlasBuilder` |
| 1× 全量占用 | 约 **1.0 M px²** ≈ 2048² 的 24% | 240 个条目 × 2 风格，单图集可容纳 |
| 2× 全量占用 | 约 **4.0 M px²** ≈ 2048² 的 96%（未计 padding/dilation） | 加 padding 与 dilation 后**装不下** → 2× 需拆两张图集，或把图集上限提到 4096 |
| alpha dilation | 会向外扩 1–2px 透明像素 | **4px/8px 留白是给 dilation 用的**，不得压缩，否则相邻图边缘互相渗色（黑边） |
| 单文件体积 | **≤ 8KB**（几何件通常 1–3KB） | 现有 64×64 样本实测 363–554 字节 |
| 整套体积 | ≤ 4MB | 与 `02` 一致 |

## 5. 禁止文字与符号（强制条款，违反即整批退回）

> 依据：`02_UI素材替换总清单.md` 铁律 1 + 本项目的实际渲染约定。**键帽上不得出现任何字母、数字、符号、字形**——`A` / `W` / `ESC` / `Shift` / `Tab` / `↑` / `↵` / `⎋` / `⌫` / `␣` 一律留空。功能由运行时 TMP 文本（`KeyText`）或外部图标叠加表达，图像本身只表达"这是一颗什么形状的键"。

**逐条强制条款：**

1. **键盘键帽与鼠标图标内，绝对禁止任何字形。** 包括拉丁字母、汉字、数字、标点、货币符、数学符、箭头符、制表符、Emoji、拼音、缩写（`Esc`/`Del`/`Ins`/`PgUp`/`Caps`/`Num`/`Alt`/`Ctrl`/`Win`/`Fn`/`Shift`/`Enter`/`Space`/`Tab`/`Back`/`Printscreen` 全部禁止）。判定：把图标放大到 800% ，只要出现可辨认的字形轮廓即不合格。
2. **禁止伪文字。** 不得画"像字但不是字"的笔画、占位条、乱码框、假拉丁文（lorem 风格）、字母变形、字距条、下划线占位。
3. **禁止数字与编号标签。** 不得在图上画 `1`–`12`（含 F 键区）、`P1/P2`、`L1/R1`、`①`、`№`、版本号、日期。
4. **禁止水印、签名、日期、URL、二维码、噪点肌理。**
5. **禁止品牌与厂商标识。** 不得出现 `Xbox` 球形 logo、`X` 球体、`PlayStation` 的 `PS` 字标、`SONY`、`XBOX`、`Series X|S`、`Steam`、`Windows` 徽标，也不得复用任何厂商商标的**轮廓形状**。
6. **方向键只能画等粗线段的纯几何三角。** 不得画成 `↑ ↓ ← →` 字符形态，不得画空心字符箭头、不得画带粗细分明的"美术箭头"。四向三角的大小、角度、线宽必须完全一致（同一 ST/DP 构件库）。
7. **Shift 只能用几何阶梯形**（上缘两级台阶 + 下缘水平线），**不得**画成字符箭头 `⇧`、不得画空心箭头、不得用文字 `SHIFT`。
8. **Enter 只能用几何折线**（先向右再向下折的拐角），不得画 `↵` `⏎` `␍` 字符；Backspace 只能用左向几何台阶，不得画 `⌫`；Tab 只能用两段几何折线，不得画 `⇥`；Esc 只能画**空键帽**，不得画 `Esc`；Space 只能画**加长空键帽**，不得画 `␣` 或横线文字。
9. **修饰键、功能键、标点键一律"空键帽 + 差异化外形"表达。** 标点键（`?` `/` `\` `[` `]` `'` `;` `,` `.` `` ` `` `-` `=`）**不得画出该标点本身**；若必须与其他键区分，只允许用"键帽上缘缺口位置"这一种几何手段区分，不得引入符号。
10. **鼠标图标禁止 `L` / `R` / `M` 字母标签**，左右键用"半边高亮"区分；滚轮禁止上下箭头字符、禁止滚动波浪线。
11. **手柄图标例外条款（唯一边界，必须严格执行边界）：**
    - **允许**：Xbox 面键 A / B / X / Y 的字母标（`xbox_button_a/b/x/y.png` + `_color_` 变体）。理由：面键身份即字母，去掉即不可辨认；这些字标是"按键身份符号"而非界面文案，且不与 `KeyIconText` 的 TMP 文本冲突。
    - **允许**：PlayStation 面键 △ ○ × □ 的纯几何图形（本身就是几何符号）。
    - **禁止**：任何型号文字（`PS5`、`Xbox One`）、任何品牌 logo、`Guide` 键上的 Xbox 球形 logo、手柄整机图（`controller_*`）上的品牌印字、触控板上的手指/手掌/滑动轨迹、摇杆上的旋钮纹路以外的任何文字。
    - **禁止**：把上述例外扩展到键盘键帽。键盘永远无字。
12. **禁止在单一图标里混入 UI 装饰。** 不得画投影、外发光、内发光、斜面浮雕、玻璃高光、圆角遮罩外的溢出笔画、由图标自身提供的焦点框或选中框（这些由 Prefab 负责，见 §0.2）。
13. **描边版本不得以"加粗实心"冒充。** Outline 版必须是**空心线性图形**，线宽恒定（1× = 4px，2× = 8px），不得出现粗细变化、模拟手绘抖动、双线描边。

### 6.2 同屏一致性（每批完成后）

- 把本批全部键帽摆成一行（模拟 308×73 键格 × 8 行），**视觉重量必须一致**：任何一颗不得明显更粗、更重、更亮或更暗。

### 6.3 自动校验脚本（可直接跑，只读不写）

```powershell
# 校验某目录下全部图标的尺寸 / 体积 / RGB 纯白 / 留白
$dir = "D:\Unity Projects\Project_Chaos\Assets\Art\Input_icon\keyboard&mouse"
Add-Type -AssemblyName System.Drawing
Get-ChildItem $dir -Filter *.png | ForEach-Object {
  $bmp = [System.Drawing.Bitmap]::FromFile($_.FullName)
  $w = $bmp.Width; $h = $bmp.Height
  $wide = $_.BaseName -match '(space|shift|enter|backspace|tab|alt|ctrl|win|capslock|lb|rb|lt|rt|l1|l2|r1|r2|trigger)'
  $okSize = if ($wide) { ($w -eq 128 -and $h -eq 64) -or ($w -eq 256 -and $h -eq 128) } else { ($w -eq 64 -and $h -eq 64) -or ($w -eq 128 -and $h -eq 128) }
  # 留白与纯白检测：扫描非全透明像素的包围盒
  $minX = $w; $minY = $h; $maxX = -1; $maxY = -1; $bad = 0
  for ($y = 0; $y -lt $h; $y++) { for ($x = 0; $x -lt $w; $x++) {
    $c = $bmp.GetPixel($x, $y)
    if ($c.A -gt 0) {
      if ($x -lt $minX) { $minX = $x }; if ($y -lt $minY) { $minY = $y }
      if ($x -gt $maxX) { $maxX = $x }; if ($y -gt $maxY) { $maxY = $y }
      if ($c.R -ne 255 -or $c.G -ne 255 -or $c.B -ne 255) { $bad++ }
    } } }
  $pad = [math]::Min([math]::Min($minX, $minY), [math]::Min($w - 1 - $maxX, $h - 1 - $maxY))
  [pscustomobject]@{
    文件 = $_.Name; 尺寸 = "${w}x${h}"; 尺寸合格 = $okSize
    KB = [math]::Round($_.Length / 1KB, 2); 体积合格 = ($_.Length -le 8192)
    最小留白px = $pad; 留白合格 = ($pad -ge ($(if ($w -gt 64) { 8 } else { 4 })))
    非白像素数 = $bad; 纯白合格 = ($bad -eq 0)
  }
  $bmp.Dispose()
} | Format-Table -AutoSize
```

> 用法：把 `$dir` 换成待检目录即可。`纯白合格 = False` 的行直接退回（Color 变体目录除外）。

### 6.4 接入级验收（美术交付后由程序执行，美术只需保证命名对）

### 8.3 已发现的技术缺口（交程序，不进美术交付物）

| 编号 | 位置 | 问题 | 影响 |
|---|---|---|---|
| **G-1** | `Scripts/Editor/ArtPipeline/IconImportPostprocessor.cs` | `IconRoot = "Assets/Art/icon"`，**该目录不存在**（真实是 `Art/Input_icon`） | 导入后处理器与图集工具扫不到任何图标，新图导入不会有正确的 Sprite 设置 |
| **G-2** | 同上 | `maxTextureSize = 128` 写死 | **2× 宽键 256×128 会被降采样到 128×64**，2× 方案直接失效 |
| **G-3** | `Scripts/Runtime/GameBase/SettingRows/KeyIconText.cs` | `SetDisplay` 里 `text.enabled = !_showIcon` → 文字与图标**互斥** | 若要"空键帽 + TMP 文字叠加"（§5 的前提），必须改成叠加而非互斥 |
| **G-4** | `Resources/Data/Input/KeyIconMap.asset` | `tint = (1,1,1,1)` 纯白，代码默认 `(0.1,0.1,0.1)` 深灰 | 资产为白、键格底也是白 → **图标在白键格里不可见** |
| **G-5** | `KeyIconMap` 143 条 / `preferGlyphVariant = true` | 库里 7 个旧 `_icon` 变体（`mouse_horizontal/move/small/vertical`、`xbox_button_back/start_icon`、`keyboard_arrows_all/none` 等）会被优先选中 | 可能选到旧画法，与新版混用 |
| **G-6** | `Functions`（手柄） | `.inputactions` 中手柄 path **为空**（未绑定） | 该行既无图标也无文字，需要一个「未绑定」占位图（建议新增 `common_unbound.png`，64×64，虚线空键帽，**不得画字**） |
| **G-7** | `KeybindBindingsPage.BindKeyRow` | `MouseButton` / `MouseText` 节点被代码整格 `SetActive(false)` | 设置界面当前**不显示鼠标键**，鼠标 13 条实际只在键格内以 `leftButton` 形式出现 |
