# 02 · UI 素材替换总清单

> 适用工程：Project_Chaos（Unity 2022.3.57f1c2，2D）。基准分辨率 **1920×1080**，`CanvasScaler.ScaleMode = ScaleWithScreenSize`、`matchWidthOrHeight = 0.5`（实测于 `RunItemWheelDriver.cs:59-60`、`RunDepthHud.cs:159-160`、`RunTeamHud.cs:163-164`、`VillageHud.cs:19`、`RunTerrainToast.cs:200-201`）。1366×768 由 CanvasScaler 等比缩放，**所有素材按 1920 基准出图即可，不需要多倍率版本**。
> 本文档是**整包 UI 换皮的唯一生产清单**。执行方（美术 agent / 外包）按本文档逐行出图即可，不需要再看代码。
> 配套文档：`01_美术执行标准与首轮需求.md`（风格基准）、`03_按键图标规范清单.md`（设置界面输入按键 icon）、`04_地图地标图标清单.md`（地图地标 icon）。
> 数据来源：`_data/A_预制体素材清单.md`（25 个 UI 预制体的控件树实测）、`_data/B_运行时UI素材清单.md`（C# 运行时拼装 UI 实测）。

## 0. 三条硬性铁律（不满足直接退回重做）

### 铁律 1 · 素材内不得出现任何文字与符号

**生成的任何一张 UI 素材，画面上不得出现任何可读内容。全部留空。**

明令禁止出现在素材里的东西（逐项检查，发现任何一项即判不合格）：

| 类别 | 禁止内容 |
|---|---|
| 文字 | 汉字、假名、谚文、拉丁字母、西里尔字母、阿拉伯字母、任何真实或虚构文字体系 |
| 数字 | 0-9 及任何计数刻痕、罗马数字 |
| 标点 | `，。、；：！？（）【】《》""''…—` 及 `. , ; : ! ? ( ) [ ] { } " ' / \ |` |
| 符号 | `× ✕ ✓ ✔ + − ± ← → ↑ ↓ ↵ ⎋ ⇧ ⌘ ★ ☆ ￥ $ % # @ & * ~ § † ‡ ● ▲ ◆ ○ □` 及任何字符形态 |
| 伪文字 | AI 生成图里常见的「像文字但不是文字」的乱码、扭曲纹章字母、篆刻伪字、符文、铭文、字母浮雕 |
| 数值/标签 | 血条上的数字、等级数字、货币数量、星级、进度百分比、编号 |
| 商标/水印 | 任何厂商 logo（Xbox / PlayStation / 键盘品牌）、生成器水印、签名 |

**允许的只有「纯几何形状」**：矩形、圆、圆角矩形、环、扇形、三角（等粗线段的几何三角）、折线、点、渐变、噪点纹理。
方向类交互件（下拉、翻页、返回、折叠）只允许用**等粗线段的纯几何三角或折线**表达，不得画成 `←` `↵` `⎋` 这类字符字形。
键盘键帽除轮廓与底色外一律留空，功能靠运行时 TMP 文本 / 独立图标叠层表达（详见 `03_按键图标规范清单.md`）。

> 原因：本工程 UI 的文字 100% 由 TextMeshPro 在运行时写入（中文本地化会换语言），素材里烘死任何字，切语言就废；且 AI 生图无法保证字形正确，只会产出伪文字污染画面。

### 铁律 2 · 同类控件必须复用同一张 Sprite

**本清单的每一行 = 一个独立的素材文件。同一复用组（G- 组号）只出 1 套文件，禁止按界面重复出图。**

错误做法：给「地图面板」画一张面板底、再给「交易面板」画一张面板底、再给「背包」画一张。
正确做法：三处全部引用 `G-PANEL-01` 的同一张 `UI_Panel_Main.png`，差异靠九宫格缩放、tint、标题栏叠加实现。

本工程实测：现有 200+ 张 UI 贴图里，约 **60 张的核心资产承担了全部 25 个 UI 预制体 + 12 类运行时界面的视觉**，其余多为历史重复件。换皮后目标是把素材总量压到 **≈ 72 个文件**（不含 `03`/`04` 的图标）。

### 铁律 3 · 复杂形状只给边框 + 极浅淡纹理

轮盘、圆环、冷却环、沙漏等**形状复杂且可能带动画**的件（见第 5 节专项），**只允许出：干净的边框 + 极浅淡的基础纹理（径向/线性渐变、低对比噪点）。**
不得加：花纹、浮雕、金属高光、宝石镶嵌、飘带、云纹、方向性装饰、投影、任何不对称装饰。
原因：这类件会在代码里旋转/缩放/fillAmount 动画，装饰会被拉伸扭曲、旋转穿帮、遮罩边缘露馅，且运行时叠加的图标与文字会被装饰抢注意力。**越素越可靠。**

## 1. 技术规格（所有素材统一）

| 项 | 规格 |
|---|---|
| 格式 | PNG-32，直通 Alpha（Straight Alpha，**不要** Premultiplied） |
| 色彩 | sRGB。素材本身不带色调倾向，主色由工程内 tint 控制 |
| 画布尺寸 | **严格按 §3.0.2「出图权威尺寸」**（该表按各组最大实际显示尺寸重定；与 §2 表的画布列不一致时**以 §3.0.2 为准**），不得自行放大/缩小（尺寸与布局、九宫格边距绑定，改了会错位） |
| 九宫格 | 按 §3.0.2 的 Border 列在 Unity Sprite Editor 里设 Border，并设 `Sprite Mode = Single`、`Mesh Type = Full Rect`；不设 Border 的件会拉伸变形 |
| 透明区 | 九宫格 border 以外的可拉伸区**必须完全透明**（alpha=0），否则拉伸会出现色带 |
| 留白 | 描边不要贴画布边，四周至少留 1-2px 透明，防止采样溢出 |
| 抗锯齿 | 边缘 1px 过渡即可，不要外发光、不要描边柔化到 3px 以上（会糊） |
| 命名 | `<类别>_<名称>_<状态>.png`，状态用 `Normal / Hover / Pressed / Selected / Disabled / On / Off`；不带尺寸后缀 |
| 目录 | 换皮后落在 `Assets/Art/UI2/<NN_分类>/`（按本清单的「分类」列分组） |
| 压缩 | 单件 ≤ 8KB（纯几何可压到 2KB 以内）；整套 ≤ 4MB |

**九宫格 Border 写法**：`左,下,右,上`。例 `48,48,48,48` 表示四边各 48px 不拉伸。
圆形/扇形/整件图形件 Border = `0,0,0,0`（不可拉伸，只靠 localScale 或按尺寸出图）。

### 3.3 复用逻辑小结（为什么这样归组）

1. **按"控件语义"归组，不按"界面"归组**。同类控件在不同界面必须同图——这是 `G-` 前缀体系的全部意义。
2. **面板底是最大的一块复用**：12 个功能面板根节点实测都是「纯色 Image + 标题」，底板由脚本统一铺 → 天然一张图服务全部界面。
3. **Tab 与按钮必须分开**。二者尺寸接近，但语义不同：Tab 表达"当前在哪个分类"，按钮表达"执行这个动作"。混用会让选中态无处表达（现状正是如此）。
4. **状态靠同组多文件或 tint，不靠换组**。品质五色、条七色、行选中态都属于同一组的变体。
5. **不为小尺寸另出图**：九宫格能解决的一律靠九宫格；只有 `G-SYS-01` 因压缩比过大（554×934 → 150×200）例外。

### 5.1 快捷选择轮盘扇区 `G-HUD-06`（最高优先级复杂件）

**来源实测**：`Scripts/Runtime/MVP/View/RadialMenuView.cs:28-31,72-96` + `RadialMenuSkin.cs` + `RadialWedgeGraphic.cs`

| 参数 | 数值 | 说明 |
|---|---|---|

| 文字 | Name 112×38 / Count 90×20 / Shortcut 50×22 | 全部 TMP 运行时写，**素材留空** |

**必须遵守的形状约束**：
1. 每个 sprite 只画**一片**扇区，其余 600×600 区域 alpha 必须为 0（透明），否则旋转后互相遮挡。
2. 扇区必须**径向对称**：不能有光从左上来、不能有单向高光、不能有纹理走向。因为整片会被旋转到任意角度。
3. 边框线宽恒定（建议 2px @1×），内外沿圆弧用同一线宽，弧段端点不必封口（相邻片会贴合）。
4. 中心孔（**r < 79**）必须完全透明，那里是图标与文字的落点。
5. 内环展开时缩到 0.58 —— 线宽会视觉变细，所以**内环素材的线宽可比外环粗 1px** 作为补偿（可选，若内外环共用一张则取中间值）。
6. 输出 **1× = 600×600**。若为了清晰度出 2×，则 1200×1200，但 Unity 导入时 Max Size 必须够大，否则会被压回 1024 导致细边框糊掉。

**生产结论（写进交付说明）**：
> 轮盘扇区形状复杂（环形扇区、任意角度旋转、缩放动画），且运行时在其上叠加 30×30 图标与三行文字。
> **因此本组素材只允许：1 条恒定线宽的边框 + 扇区内部极浅淡径向渐变（两色差 ≤ 8% 明度）。不得加花纹、纹理图案、高光、投影、内发光、任何不对称装饰。**

## 附录 B · 术语对照

| 术语 | 含义 |
|---|---|
| 九宫格 / Border | Unity Sprite 的 9-slice 边距，让一张图拉成任意尺寸而不变形 |
| tint | 运行时 `Image.color` 乘色，用来让一张中性灰素材变出多种颜色 |
| 预制体 / prefab | Unity 可复用 UI 模板 |
| 壳预制体 | 文件里只有根节点 + 标题，真正控件由 C# 在运行时 new 出来 |
| 实控件预制体 | 控件在文件里真实存在（SettingPanel、SettingRow_*、MainMenuPanel 等） |
